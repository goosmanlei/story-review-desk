# 视听制作与统一实体工作区

顶部选择当前视听集，左侧选择当前场镜。每镜嵌入与实体大卡相同的基础信息、素材分组和右侧素材阅读区；集场工作稿在悬停或聚焦时读取。所有制作内容原地维护，改镜头不新建父场或父集版本。

## 准确组成与内容

`AV_EPISODE.scenes`、`AV_SCENE.shots` 与需求归属使用当前对象的稳定地址；输入锁、准确故事版本和对象配对继续校验。旧制作地址只映射真实候选、原意见或明确退役说明，不能按最新稿冒充旧组成。

当前写入使用 `reading_contract: audiovisual-three-part-v1`。集场仅保存准确组成；镜头保存 `purpose`、`key_states` 和 `products`，另保留来源、既有时长与实际身份依赖。`purpose` 解释本镜给观众的新理解或感受，不由系统按动作模板生成。

`key_states` 是有独立素材准备需要的镜内时刻。每项含稳定 `id`、自然语言 `description` 与准确 `requirements` 引用；同一状态可关联多个需求，同一需求也可服务多个关键状态；同一状态内不重复列同一个需求。需求须属于本镜对象，允许显式复用本镜较早设计下的准确需求；不能借另一镜需求。没有中间状态就不制造占位。

`products` 按真实制作顺序保存 `{label, requirement}`；工作区读取本镜全部直属需求，按机位、首帧、视频、工程及其他实际用途纵向分组列出双列素材，包含没有列入 products 的主／反机位。初入选择首个实际素材的当前方案，返回恢复本镜仍合法的阅读选择。上游参考不自动成为产物。缺少准确需求、没有产物或没有模型方案分别显示具体空态。工程保持工程身份，通过共用卡读取 ZIP 等原件和交付要求，不冒充生成视频。

每个来源分组展示素材小卡；涉及多个关键状态的同类产物按准确来源分小区，标题问号只显示真实说明，移出即消失；原意见继续从准确评论原文回查。点击素材后，仅在右侧显示当前方案或选定候选的参考、模型／参数和完整 Prompt。候选读取提交快照，历史缺口不借当前内容补写；没有制作版本按钮。

参考列表保留实际素材身份、候选、组成、哈希及裁切／时间范围。共用卡关闭后恢复镜头位置、产物选择和各自评论草稿，浏览不改变生成输入。

## 镜头的统一实体身份

`production-entity-v2` 将 ENTITY 与 AV_SHOT 作为同一实体契约的类型分支。镜头继续使用原 AV_SHOT、object_id、ASH 编号和集场组成，不复制影子 ENTITY，也不把镜内 key_states 复制成角色 STATE。读取记录提供 entity_contract 与 entity_type；写入校验拒绝 ENTITY 的 shot 类型。关系端点、管理索引、评论和导出沿相同稳定身份解析。

实体管理只显示全剧或指定集场的关系图，含无关系节点；普通切入默认全部集场，明确范围链接保留定位。普通实体沿实际制作引用及素材用途确定范围，镜头沿集场组成确定范围。真实关系保留方向和摘要，“本镜涉及”从镜头引用及状态归属去重派生，不写入第二套关系、不推断实际入画。缩放、平移和卡片返回保存当前范围的位置；实体及镜头大卡不再重复绘图。

基础信息中的故事出处直接打开准确场的完整正文并高亮所引段落。来源条目平铺，歌曲全词和实际演唱选段同在基础信息中，仍分别保留各自的事实及出处。

## 当前工作稿与准确反馈

`audiovisual_notes` 每集／场一行，`body` 最长三万字；读取随集场导航返回；`POST /api/production/working-note` 使用 `object_id` 和 `expected_etag` 防止覆盖并发更新。更新不产生设计修订或历史副本；不允许为镜头写这类工作稿。完整导出保存当前正文与更新时间。

叙事目的、状态描述、参数和 Prompt 沿原对象／修订／字段的文字锚点反馈。连续跨块和分段圈选保持准确端点，保存／刷新／关闭／重开不改绑。详见 [评论范围](comment-checklist.md#组合阅读中的准确文字范围)。已有 `production_reading`、`scene_reading` 是其他阅读入口的准确投影能力；视听镜卡不再据此建立动作对白或共同条件副本。准确 Prompt 和锁定剧本继续保存影片实际要表达的内容。

集评论计数覆盖该集准确组成与直接素材的定义、候选，含已关闭评论且去重；不混入无关上游或故事评论。来源按钮读准确故事场并高亮引用范围；来源缺失不回落同名或最新版。

## 素材关系与执行路线

实体、素材需求／原件与镜头关系统一为 `RELATION/business`，一对稳定端点一份当前描述。生成所需约束由作者融入完整 Prompt，提交时保存实际所用内容。旧 MATERIAL_RELATION 已退役，仅保留必要地址映射。

必需参考参与当前路线校验。可选参考由 enabled 决定；条件参考需明确判断条件；one_of 参考必须为其 group 选择 route。计划的 selected_routes 与 conditions 参与冻结定义。只检查当前执行路线的缺项和循环，不能让未选路线误阻断，也不能让描述关系自动提交输入。

`POST /api/production/material-route` 使用唯一操作 id、requirement_id、当前 `expected_content` 和既有路线字段。读取后在同一事务核对并发标记，修改唯一当前方案；重复同一载荷幂等，旧标记拒绝，不创建新版。

## 准确参考选择

小卡和 Prompt 标记通过原始有序输入槽位打开同一详情。直接参考仅通过小卡或 Prompt 浮层中的候选按钮选择和取消；详情不再提供第二套选择按钮、候选待选操作或上下说明。间接参考只读，不修改共享需求。浏览、比较、选择参考和实际采用互不推断。

`POST /api/production/shot-reference` 沿既有槽位协议选择准确 candidate、component_id，并携带消费需求的 `expected_content`。input_key 校验原槽位，候选与原件必须匹配。参考使用完整原件，提交 crop/range 会被拒绝；旧范围随重新选定同原件或取消清除。历史实际提交继续保留当时范围。

当前方案的直接参考小卡保持原边框、标题、缩略图和占地，图像输入未选定原件时在原缩略图位置显示占位图，选择后换为准确原件；原状态行直接展示22px高的候选按钮；超宽仅该行横向滚动。按钮本身用对勾、样式与 aria-pressed 表达选择，不另加选中说明或常驻预览按钮。图像、声音及视频均可悬停或聚焦预览准确原件，播放器只在主动操作后播放，离开或关闭即停止。浮层使用浏览器顶层，桌面最大宽560px、图像展示高480px，按视口余量收缩；不设置关闭按钮，鼠标移出自动关闭，跨大卡及滚动容器可操作；Esc关闭，ArrowDown进入浮层，触屏按住预览、横滑不选择。多原件在临时浮层明确选择，不取第一份。保存期间仅禁用本次输入的选择控件并保持最后确认的标记，不插入“正在保存”文字。零候选显示“暂无候选”，读取失败显示真实错误及重试，所有状态保持卡片尺寸。历史提交和间接引用保持只读，素材名称继续进入准确详情。

Prompt 的媒体 @ 引用悬停或聚焦时显示同宽预览，顶部额外留一行候选按钮，下面默认显示该输入已选定的准确原件；未选时显示占位图。悬停或聚焦候选按钮只临时切换预览，图像离开候选按钮后恢复已保存选择；音视频移到浮层内部的播放器时保留临时预览，允许主动播放，退出浮层停止并复位，键盘切到播放器等价。两处候选按钮均以背景和边框变化表达悬停；列表按钮在鼠标或焦点进入对应浮层时保持高亮，预览关闭才解除。临时试听中的候选保留预览样式；对勾仍只表达已保存选择。点击选择或切换，再点已选候选取消，与参考小卡共用同一消费方案、输入位置和保存回执。当前 @ 标签只显示素材身份，候选按钮表达选择，切换后不会残留旧候选号。多原件仍须明确选择。浮层挂在 Prompt 正文之外，不改变原文、评论定位和点击进入详情的行为。准确媒体输入的 `reference_contract` 字段用于身份校验，不是排除预览的标记；只有文字等非媒体输入不绑定媒体浮层。共用 Prompt 引用投影在素材详情和视听入口均保留作者的 @ 标记到准确输入位置的映射。历史提交及间接引用仅预览其准确原件，不加载可修改的候选列表、不借用当前方案选择；音视频仍主动播放，退出即停止。

素材卡先在未挂载的父容器内组装，再加入页面；此阶段不能把参考小卡当作已关闭而删除监听。候选小卡在已挂载的读取阶段登记共享回执监听，Prompt 浮层在实际打开时登记、关闭时退出。两者都读取该消费方案最新槽位，保存及明确取消后只向变化的输入位置通知，刷新其按钮、缩略图和浮层；不相关素材的控件不重绘、不切换禁用状态。不同输入的保存可排队，依次使用最新回执标记；关闭的读卡不接收迟到刷新。

可见小卡及打开的 Prompt 预览通过 `GET /api/production/reference-candidates?material_id=...&media_type=...` 获取轻量候选及原件摘要，复用短时请求，原件只在预览时读取。一次消费方案的保存串行承接每个回执的并发标记及原输入位置；未知结果只能以原操作 ID 重试。版本冲突后显式 `GET /api/production/shot-reference?requirement_id=...` 重新读取当前选择和标记。回执同时提供所属实体的轻量读标记，只在其余对象仍匹配时推进打开中的工作区。独立详情显式传入自己的工作区，回执同步其消费需求摘要与读标记，使保存后加载历史仍使用当前身份；迟到响应不覆盖其他消费者。

小卡点击未选候选保存或切换，再次点击已选候选明确取消整个该输入：POST传 candidate:null，只清除此消费方案这一槽位的候选、原件、crop/range、sha256与material_selection，保留素材需求引用、关系和用途，其他输入、消费者、上游与历史不变。普通跨素材取消后回到未选需求。本素材候选取消保留准确ASSET出处、未选状态和只含素材身份的归属，清除候选ID、原件组成与范围，不创建指向本需求的依赖；准备与执行继续阻断，重新选择后恢复。取消后重开保持未选，重新选择不复活旧范围。取消是新的操作ID；保存失败保留已确认状态，结果未知只能按原ID和原载荷重试，不按重试次数反向切换。完整原件的重复保存不产生变更；同请求重放仍幂等。旧 `preserve_bounds` 参数不再保留部分参考。旧关系端点为原件时，仅以准确候选归属证明它属于此素材需求，允许取消后继续保留该关系；不按名称或主体推断，也不改写历史关系。

旧版号和 `baseline_id` 只为准确历史地址映射保留；新方案不建立版本。缺失或已退役输入明确拒绝，不能改用最新候选。

保存回执返回当前稳定地址、新的并发标记和准确槽位。下次修改重新取得该标记及 input_key；同一操作身份只能重发相同载荷。

详情中的局部区域、时间段、参考片段试听和范围保存控件全部移除。音视频可完整播放准确原件；评论圈选仍只用于评论定位，与参考选择独立。已有当前方案的范围设置通过受并发校验的 `whole_references` 操作清除，仅改当前输入的 crop/range，不改候选、原件、关系、用途、Prompt、调用与历史快照。实例正式数据须沿准确增量发布，不从测试副本覆盖。

回归入口为 `tests/prompt_candidate_preview.test.cjs`、`tests/reference_candidate_picker.test.cjs`、`tests/ui_unification_requirements.test.cjs`、`tests/shot_reference_loop.test.cjs` 和 `tests/test_reference_candidates.py`；真实浏览器、实例版本与正式数据保护由实例任务留证。

新调用、readiness 和执行包共用准确选择校验：缺版本、候选、原件、错配、非法范围或所选路线循环均阻断。CALL 只记录实际提交的直接输入，并保留原槽位对应；不把未执行路线或间接参考伪装成调用输入。

## 生成保护与物理退役

所有逐对象审批及其历史正文退出；旧审批写入口不再提供，生成准备不要求决定或评论。准确输入、原件选择、实际调用授权和失败幂等仍分别校验；读稿、切版、采用旧原件或执行清理均不授予付费权限。

`audiovisual_cleanup` 在准确清单和事务内清除旧视听专属字段、正文、作者映射以及视听关系的解释副本，独占设计决定删除。执行时重新检查头、历史和评论；若新增有效评论需要保留，整次删除拒绝。关系端点、路线、实际 Prompt、CALL 和原件不属于这些冗余字段。

真实调用的必要上游内容已进入提交快照，旧集场镜全文与历史组成树退出活库。最小退役映射仅保存身份和摘要，不能还原旧全文。

Schema 14 完整包与空实例恢复采用 [当前制作与候选](current-materials.md) 契约。普通增量器不覆盖活库；有意删除与原地模型切换必须沿实例专门迁移和共享写入窗口执行。

回归：`test_audiovisual_reading.py` 覆盖状态归属、并发工作稿、评论阻断、事实篡改、旧格式再导入及空恢复；`ui_unification_requirements.test.cjs` 覆盖三部分、产物顺序、准确切版／链接和共用卡历史状态；`ui_material_independent.test.cjs` 覆盖旧版无定义或仅有真实调用。`shot_reading.test.cjs` 保留准确投影和旧评论／草稿端点保护。实例另提交真实浏览器和逐集叙事验收；测试不能证明声画效果。
