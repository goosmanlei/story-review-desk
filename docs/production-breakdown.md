# 视听制作与多需求审阅

视听制作按视听集／场／镜组织内容。顶部选择集和准确设计版本，左侧定位场镜，正文按动作与对白连续阅读，摄影、表演、声音与剪接就近呈现；场尾集中比较准确原件、用途和制作方案，并以规范需求身份去重。素材标题、类型、版本总数、候选总数与具体参考选择分开表达。

## 准确编排与来源

`AV_EPISODE.scenes` 固定场修订，`AV_SCENE.shots` 固定镜头修订。集与故事集边界一致；场可覆盖同集多个故事场或部分正文，子项范围必须在父项范围内。每一级 `sources` 均含准确分集修订、场号及正文块 ID。不存在“当前父场自动替换旧镜归属”的行为。

切换集设计版本先读所选准确集的组成，再按原场镜对象身份确定该版修订及真实父场；标题和序号不用于猜测。地址中的 `breakdown_episode_revision` 固定所选集修订，目录与场正文请求分别用 `episode_revision` 核验，刷新或同一孩子被多版复用也不反查到另一集。旧链接未带集修订时仍沿既有准确子项读取；成功定位后补上准确集身份。

目标不在组成中、准确修订不符或有多个父位置时，保留所选集版本并显示无法定位的原因，正文不默回第一场；沿现有场镜导航可继续选择。移场时按目标组成显示真实父场及条件。集方案、场条件、镜头原字段、状态依据和目录展开在可对应时保留；定位服务于同一场镜阅读，不承诺相同像素。未提交意见仍按准确原修订保存，不随比较迁移。

来源按钮分别打开准确故事场完整正文，并高亮此引用中的段落。跨故事场来源分别可读，缺少可选场标题仍能展示准确正文；不存在或失效的引用明确报错，不回落最新或同名对象。“故事剧本”页通过制作关联分别展示实体／状态和视听设计的来源联系。

每镜说明叙事目的、构图、空间、轴线、运动、动作起止、表演、灯光、色彩、剪辑、声音、连续性及估计时长。`continuity_context` 是理解连续性的背景，不能当成该镜实际出场状态。

连续阅读只自动合并全文完全相同且作用相同的字段。不同构图、状态、动作顺序和发声事件分别保留；同句对白可能是两次真实发声，不能按文本或人物名合并。没有实例编排时，完整显示原设计和必要声音，不猜测省略范围。

## 作品阅读与准确原文

动作与对白沿 `config/instance.json.scene_reading` 的 `exact-prompt-reading-v1` 读取：不可变修订、对象、scope、字段、整份 UTF-8 Prompt 哈希及 Unicode 字符区间共同定位。动作、原词、反应、未定词句和必要细节按原顺序出现，不用当前方案补写旧候选。映射失败时保留完整原文并说明原因。

可另由实例作者提供 `production_reading`（`exact-review-composition-v1`），组织场、镜头、人物、状态、需求或用途的专业阅读顺序。`entries` 以不可变修订 ID 为键，每项包含：

- `object_id`：准确对象；`requires`：必须同时展示的准确记录修订。缺少任一伴随内容时显示完整原字段。
- `sources`：必须覆盖 `production_text_blocks` 返回的全部块；每块保存 UTF-8 哈希、处置和具体理由。处置为直接显示 `display`、已在明确位置表达 `represented`、交给准备工作 `preparation` 或当前阅读范围外 `outside_scope`。
- `sections[].parts`：原 `block_id` 和 Unicode 字符 `start`／`end`。正文从原块提取，不保存另一套作品文本。一个块只读部分区间时，作者须说明其余意思在哪里保留或为何不属于当前工作。

系统验证归属、哈希、区间、逐块说明和伴随内容，不声称能够自动证明语义完整。作者必须先读准确来源，逐项比较动作、表演、摄影、声音及剪接；不能按关键词删句或首字段截断。新修订没有编排便回到完整原文，不复制旧映射。

面向作品的专业内容直接可读。模型参数、重复 Prompt、生成时自检和确定性执行检查由后台准备与真实调用记录承担，不成为默认人工待办。原件、当前人工意见与适用范围直接相邻；历史版本用原有版本选择器读取，历史没有的内容保持未知。无生成原件、缺 CALL 和冻结版缺要求分别说明，不制造候选。

评论继续绑定原对象、修订、块及原始偏移。当前可见区间直接高亮；旧意见或草稿指向未呈现的区间时，打开该准确原块供回查与反馈，不找近似句，也不把完整技术信息堆成另一个默认阅读页。跨块圈选或不满足伴随条件的草稿使用完整原文字面。图像区域、音视频时间、文件组成和返回草稿沿共用组件保持。

确定性验证见 `tests/test_review_composition.py`、`tests/test_prompt_reading.py`、`tests/shot_reading.test.cjs`；真实实例另验连读、旧意见回查、图像与片段、版本和返回。工程／文档需求仍直接提供原件下载与准确要求，文件交付不代表合成效果通过。

## 一镜多个需求

`REQUIREMENT.scope` 精确绑定镜头。每镜可有正面、侧面、首帧、声音和视频等多项需求，不限制唯一视频方案。制作方案入口与共用卡片共用同一身份；当前选中 ASSET 时仍解析回所属需求统计，候选数不因直接输入和需求关联重复计算。

镜内需求默认读取最新绑定此准确镜头设计的需求，准确链接和手动选择优先。该需求与制作版本完整定义不同时，直接显示原素材要求与有序准确输入；历史完整方案仍按原修订回查，其参考只读，沿“查看当前准备方案”另读可编辑的当前目标，关闭后回原设计。同设计多需求修订的选择与缺失边界见[素材版本](material-versions.md#评论与采用)。某版没有结果就显示该版待生成，不借另一版候选；真实候选入口先展示原件与已有判断；执行追溯仍绑定自己的 CALL。实体／素材普通卡的默认浏览策略仍可优先展示有结果版本，不能把浏览默认值当成已选参考。

`shot_material_id`、`shot_plan`、`shot_candidate` 保存当前需求、版本和候选；跨清理基线使用 `shot_baseline`。同需求双候选比较支持跨版图片、声音与视频，比较不写入引用或采用。切换和关闭比较会暂停其播放器，避免与底层音轨叠播。

## 素材关系与执行路线

`MATERIAL_RELATION` 固定上游准确需求或候选、下游需求身份、语境、用途、保留项、变化项和检查方法。类型定义包含稳定 ID、名称、版本、端点、方向及属性含义。通用语义为 reference、reuse、variant、alternative、continuity、description；后面三类只作说明，未知自定义关系必须显式使用 description。

必需参考参与当前路线校验。可选参考由 enabled 决定；条件参考需明确判断条件；one_of 参考必须为其 group 选择 route。计划的 selected_routes 与 conditions 参与冻结定义。只检查当前执行路线的缺项和循环，不能让未选路线误阻断，也不能让描述关系自动提交输入。

`POST /api/production/material-route` 使用操作 id、requirement_id、expected_revision、plan_number 及 action/key/value。route 的 key/value 是组和路线；condition 是条件名和布尔值；optional 是输入索引和布尔值。接口校验准确计划和可用选项，冻结方案修改建立新版，操作 ID 重试幂等。

## 准确参考选择

小卡和 Prompt 标记通过原始有序输入槽位打开同一详情。直接参考可“选为方案参考”；间接参考只读，并指明其上游所有者，不能静默改写共享需求。浏览、比较、选择参考和实际采用互不推断。

`POST /api/production/shot-reference` 接收 id、requirement_id、expected_revision、plan_number、index、input_key，以及 material_id、number、candidate、component_id 和可选 crop/range。candidate 是准确对象／修订引用；null 表示仅选版本，仍缺候选。input_key 来自服务端原槽位指纹。图像范围使用归一化坐标；音视频范围用秒并须处于原件内。

已选入口携带服务端槽位的 `baseline_id`（当前素材版本编号所依据的收敛身份），与普通准确素材链接共用版本校验。没有基线的旧链接继续按既有映射解释；删除身份、失效基线和不属于该版的候选拒绝读取，不改为最新版本。

保存回执返回消费需求的准确 `revision_id`、素材方案 `number`、`baseline_id`、`frozen`、全部 `slots` 及 `selected_index`。后者是新草稿中的输入位置，可能不同于冻结调用只含有效路线时的位置。下一次保存使用回执中的准确修订、方案号与新槽位指纹；同一操作编号只可重发相同请求。

消费小卡直接显示已保存的时间范围或已登记裁切。详情中的相同选择显示已保存，编辑后变为“保存修改 · 未保存”；放弃范围修改恢复已保存数值。编辑值按素材版本、候选和文件组成分别保留，切换只用于浏览，试听／预览组成不能作为原件保存。空数值先拒绝，其他范围校验继续由服务端负责；失败保留当前编辑值。

音视频参考的范围控件紧邻播放器。“试听已保存片段”直接使用此消费位置保存的准确版本、候选、组成及起止；调整后变为“试听未保存范围”，只有明确保存才推进生成输入。放弃恢复保存值，修改范围时暂停正在试听的旧范围。播放器的完整播放入口明确区分原件和预览，从文件起点播放全长；暂停控件表明当前播放的是已保存片段、未保存范围、评论选段还是完整文件。评论圈选与参考范围独立，试听参考不建立评论圈选，清除评论选段也不扩大参考试听。关闭、切换及读取失败沿原生命周期保护，不替换准确文件。选段终点另按真实媒体时间调度，避免仅靠低频 `timeupdate` 事件迟停。

一次保存只绑定发出请求时的消费方案和位置。响应推进该编辑会话的准确身份，但不会覆盖保存中继续输入的值或将已保存提示刷到另一候选。关闭时仍有请求就等待其结果，再回到原消费位置刷新；进入其他卡时先等待返回，不重绘新读卡。已切换页面或失效的原消费入口不会接收迟到刷新。选择成功不替代设计／方案采纳、原件认可、文件和谱系等生成准备条件。

回归入口为 `tests/shot_reference_loop.test.cjs`、`tests/media_location.test.cjs`、`tests/ui_unification_compatibility.test.cjs`、`tests/version_consolidation.test.cjs` 与 `tests/test_shot_references.py`；真实浏览器、实例版本与正式数据保护由实例任务留证。

替换原件而未再次提交范围时清除旧 crop/range，不能把另一候选的范围带入新原件。其他槽位不变；冻结后建立新方案，真实调用和旧意见不变。同操作 ID 同载荷重试返回原结果，不同载荷拒绝。读取中切换、关闭或转工作区后，迟到响应不覆盖新对象。保存后等待弹窗历史返回再刷新，草稿仍绑定原文本修订。

新调用、readiness 和执行包共用准确选择校验：缺版本、候选、原件、错配、非法范围或所选路线循环均阻断。CALL 只记录实际提交的直接输入，并保留原槽位对应；不把未执行路线或间接参考伪装成调用输入。

## 评论、采纳和导航

`GET/POST /api/production/acceptance` 读取或保存准确设计／需求采纳。请求带 expected_revision 和 expected_decision；集或场的决定覆盖当时准确子项，子项后续撤销使上级部分采纳，重新采纳上级可形成新的明确决定。单调决定序号用于同一秒内的先后顺序，不依赖时间字符串排序。

集评论计数按本集准确设计及其直接需求的定义、候选等评论目标取并集，包含已关闭评论；不混入不相关上游或故事评论。版本、评论、草稿、返回位置、分页与焦点沿共用组件保持。390 像素下场头按钮可换行，媒体比较纵向排列；管理页缩放只重排当前页集合。

## 读取与退役

主要读取为 `/api/production/breakdown`、`/context`、`/materials`、`/summary`、`/material-relations`、`/story-related` 和 `/source`。CLI 的 production-breakdown/context/materials/summary 对应同一契约；详细参数见模块及 `--help`。

旧镜头页 URL 可进入统一入口，但其中的旧对象与修订参数仍须严格解析，删除目标显示不可用。旧 PREPARATION、SHOT_DESIGN、组合和历史类型不再导入或恢复；旧 material-model/plan/round 迁移与回滚的 HTTP/CLI 写入入口已移除。仍保留的只读 material-model-verify 用于当前共享存储完整性。

自动回归覆盖编排来源、范围、版本冻结、路线循环、准确选择、并发、评论及迟到响应。`tests/shot_reading.test.cjs` 另覆盖同文/独立子串、不同镜头覆盖、准确旧共性、原字段定位和重复对白边界。`PYTHONPATH=. python3 tests/create_shot_reading_fixture.py <新隔离目录>` 可创建无媒体调用的显式历史阅读夹具，包含独立内容、镜头例外和三个旧字段意见；仅用于隔离实操，不导入正式库。实例必须另行操作真实浏览器的集场镜、来源、多需求、比较、评论、采纳、实体与素材页，并回归故事和方法页；测试通过不替代页面证据。

集版本比较回归入口为 `tests/edition_context.test.cjs`、`tests/test_edition_context.py`，与既有 `production_page_lifecycle.test.cjs` 联合覆盖最后选择和离页守卫。`PYTHONPATH=.:tests python3 tests/create_edition_context_fixture.py <新隔离目录>` 创建明确非作品的复用、移场、多父不唯一和对象缺席夹具，同时保留旧字段意见；夹具不得写入正式实例。真实浏览器、正式发布及实例数据保护由故事任务另行留证。
