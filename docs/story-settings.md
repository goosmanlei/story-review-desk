# 故事设定与素材关系

故事设定回答“是谁、是什么、在哪里、怎样关联”；素材管理使用同一永久主体，维护表现、需求、参考、资产族与实际版本。F 来源事实、A 改编、L 制作锁定、U 待核分别记录。显示场号、同名文件与旧稿不能替代永久身份和精确修订。

## 查阅与登记

- 主体档案与空间设定使用语义页签。主体节点位置固定，可平移缩放；单击主体高亮直接关联，双击或 Shift+Enter 打开详情。
- 单击关系线或文字只强调这条关系及两个端点，再次点击可取消。多重、反向关系独立呈现，不删除其他节点。
- 登记入口仅在顶部搜索旁；打开弹窗不保存。明确保存才合入本模块草稿，取消不留下空主体，冲突保留作者输入且不自动重试。
- 空间卡只展示地点关键信息与精确关联图片，右上角编辑，不跳转素材。图片在当前页面模态放大，ESC 或 X 关闭并恢复焦点，底层地点卡保持打开。
- 空间锚点来自已发布资料，未知位置留在独立目录；方位、坐标系、区域和机位不猜测或镜像。

## 通过 Codex 整理

把原文、剧本与空间说明显式登记到项目来源，告诉 Codex 本次依据、范围和目标模块。页面不再提供“依据资料整理设定草稿”模块。Codex 按需读取精确来源 revision/SHA，整理有证据的主体、关系、空间与素材建议，再经所属模块保存、预览和确认。

候选不等于已采用源；作为设定依据时保留候选身份和正文哈希。没有实际观察的原图、音频和视频保持 UNKNOWN，不以文件存在或元数据代替观察。

## 写入与影响

同一 domainGraph 保存业务内容，domainOwnership 独立维护归属，不改原业务哈希。SETTINGS 与 MATERIAL 各自保存 changes（collection、id、beforeHash、value），不提交无边界整图。归属不明先核对；确认只应用本模块变更，保留其他草稿。

保存、预览和确认校验发布、草稿和精确来源。旧初始化建议只读核对，可显式转交新增或修改，不转交删除、不覆盖已有修改。历史版本及实际生成输入不得换绑。

主体描述可能包含生产身份，变更只影响引用此设定的素材；人物信息卡文案属于独立表现，不无差别废弃纯净画面。故事关系、连续性、制作参考及成片组合分别登记，关系声明不证明实际模型输入。

## 集场与素材

素材目录按媒介、主体类别、永久集、永久场及进度筛选，选中后再次点击可取消。主体缩略图须来自精确关联、未作废且版本、路径和 SHA 完整的图片；缺图使用统一图标。

筹备用途与正式输入分开。候选、准备稿或目录变化后，按每场完整局部依据及每条需求、条件独立重核：未变项保留，变化项待核。不能整体清空用途，也不能只比较正文 SHA 而忽略承接和因果。显式 revalidate-preview/apply 原子追加新准备稿和用途修订，保留旧证据。

正式用途仍须已采用且同步的对象及实际 familyId/versionId/SHA。需求、参考或筹备用途不证明生成、放行或取得权利。本地实例唯一权威，只读镜像不接受正式写入。更多流程见[使用与维护](system-management.md)。
