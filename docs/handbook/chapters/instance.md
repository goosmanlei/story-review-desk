# 当前项目实例册

这里将通用架构映射到你正在阅读的故事。软件和讲解模板来自核心，下面的对象与关系通过本实例的正式接口读取；不会把真实项目正文写入通用手册。

## 怎样阅读实例图

1. 选择对象类型、搜索名称，再选择一个对象。
2. 核对当前对象状态、草稿头和采用头；可以选择历史修订。
3. 看“精确输入”了解该修订实际引用什么，看“当前直接下游”了解哪些对象的草稿或采用修订引用它。
4. 普通关联单独展示，不能把同集、同场或同素材族误当作版本依赖。
5. 点击关系卡继续查看该对象。点击精确输入会固定其原 revisionId，不静默跳到最新稿。

## 读取与变化

每次进入或主动刷新读取最新数据，页面保留读取时间和版本依据。当前图不会随着后台变化自动重排；需要最新情况时主动刷新。来源身份、评论锚点、媒体缺失和历史状态保持接口返回的事实。

空白项目会显示未登记，不会生成示例故事。查询没有结果不代表整剧缺少该能力；六域数量排除历史对象；对象目录可单独选择包含历史。下游视图仅展示当前草稿或采用头中的直接消费者，不能视为全部历史闭包。
