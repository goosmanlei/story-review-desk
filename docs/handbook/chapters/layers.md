# 分层设计与页面读取

## 一次操作经过哪些层

![页面到业务事务的分层调用方向](../assets/layers.svg)

| 层 | 主要职责 | 实现入口 |
| --- | --- | --- |
| 页面与客户端 | 交互、编辑草稿、导航、圈选和阅读状态 | web/app |
| HTTP 与 CLI 协议 | 解析请求、运行期检查、响应与错误 | server/api.mjs、scripts/review.mjs |
| 应用编排与业务服务 | 将工作区动作转换为对象命令，检查领域规则 | workspace-actions、commands、各域 service |
| 读取投影 | 组合页面需要的同版本上下文 | workspaces、presentation |
| 数据访问与事务 | 稳定加锁、读写、约束、回滚 | repository、db、schema |
| 后台执行 | 领取任务、调用受控适配器、登记结果 | jobs、worker、各域执行服务 |

这是模块化单体，六个领域不等于六个独立微服务。当前事务编排和数据访问有共享模块；架构图不会假装每个领域已经拥有物理隔离的仓储。接口之间不进行 HTTP 互调。

## 页面如何读到足够的上下文

正文、关联对象、精确输入、评论和已有判断在同一只读数据库快照中组合返回。basis 列出实际读取的对象版本和 SHA。普通关联可能展示当前稿，实际输入必须展示精确修订，两类绑定分别标注。

复杂工作区使用专用读取投影以保留原版交互。投影是请求结果，不是第二套业务数据库。列表默认每页 50 项，最多 100 项；分页固定目录与筛选条件的版本。发现跨页变化就拒绝混合展示。素材分类和关系图使用轻量目录索引，索引不含 Prompt、原文、完整设计或执行记录。打开素材卡时只读取该需求与其素材族的完整内容，不自动遍历后续详情页。

## 快速与稳定是两件事

浏览器与后端的业务读取缓存各最多 24 MiB，空闲 5 分钟淘汰。目录有界加载，详情按需读取。系统不缓存第二份整剧内容，SSE 不长期占用数据库事务，心跳不生成业务修订。

编辑中的草稿、筛选、阅读位置与圈选属于浏览器交互状态。后台轮询和读取缓存失效不得顺带清空它们；切回页面也不应把新响应造成的重排误当作用户主动定位。

## 手册自身的读取

本手册由 Markdown 编译成分章 HTML 与索引，图表为受管 SVG。通用文档接口在数据库连接前处理，只读发布包内清单允许的章节与资源，支持 ETag。文档总产物预算为 2 MiB；客户端复用现有读取缓存，单章按需加载。

Next 的开发启动和生产构建阶段都会先核验并编译手册，再通过 standalone 文件追踪携带资源。生产请求只读取已构建产物，不依赖源码目录、文档编译依赖或数据库。

实例册复用现有对象读取接口；它不会增加一条可以绕开业务校验的写路径。

## 故事结构的当前方案

故事结构的创作说明、分集与视角接力、铺垫与揭晓从同一次方案读取呈现。普通入口不固定上次读取的修订号；进入、刷新、子项切换、重新聚焦及故事更新后重新核验当前工作稿。当前稿可以是草稿或待审稿，阅读不改变采用头。页面不提供历史目录或版本切换。

显式历史追溯继续读取原修订，不能换绑当前稿；从历史页面主动点击“故事结构”则回到普通当前稿入口。底层修订、评论、判断和精确引用保持原样。

## 来源资料的阅读布局

来源按登记对象并列展示，以来源性质标签说明原始、整理或辅助关系，不建立空分类层。逐字稿的部分目录独立展开或折叠，折叠不改变正文选择和阅读位置；二级目录限高滚动。来源资料页的同一个录音播放器位于正文滚动区之外，切换来源或部分时保持播放进度与状态，时间码统一控制它。离开来源资料页后不保留跨模块播放。资料原文、修订与媒体绑定仍按既有接口核验。

## 全剧制作的集场导航

镜头制作与场景剪辑的所有子步骤共用左侧“集 → 场”可折叠目录，集标题与箭头都只展开或收起该集，不改变当前集场；分集成片的集标题继续选择该集。左右两栏按自身内容采用自然高度，取消共同固定高度和两栏内部滚动。目录多集展开或全部折叠不改变右侧起点，不把较短正文拉长；窄屏仍并列呈现并允许长名称换行。当前集和场分别高亮，跨集选场使用永久身份。已核验的导航在后续检查读取期间保持挂载；仅右侧提示读取或错误，未完整核验的内容不可见且 inert，编辑与离开保护继续挂载。

目录展开状态、每集最近阅读的有效场，以及各检查和集场的正文阅读偏移，保存在当前实例与运行期的浏览器会话中。阅读恢复使用页面或实际外层滚动容器，由正文单独负责；兼容旧内部滚动记录，并保留位于正文上方的负偏移。切换后等待必要读取完成，恢复一次后停止；用户滚动、触摸、指针或滚动键操作优先于尚未完成的恢复。分集成片链接不携带隐藏场，返回场级模块时只从当前集有效场恢复选择。

这些偏好不替代显式深链。不存在或集场不匹配的永久身份继续显示定位错误，不自动绑定首集、同名集场或历史对象。导航先通过现有未保存内容保护；父页面拒绝导航时子工作区不提前切换。浏览器偏好写入失败不影响只读浏览，也不代替独立的编辑草稿保留与离开保护。

## 待确认地点如何进入地图

空间工作区将原 SOURCE 的空间规格与版本化位置 NOTE 分开投影。已有锚点仍使用规格中的坐标和门向；没有已发布坐标的地点可在地图内的独立待确认区域显示并打开永久地点卡。该区域不生成地理锚点、连线、路线或制作几何。

当前、陈旧、冲突和异常旧记录分别呈现，原 NOTE 与精确依据都可追溯。位置提案不加入已发布空间目录；浏览器搜索和阅读不改写草稿或采用头。

## 素材主体与用途投影

素材需求及素材族通过 `subjectBindings[]` 返回实际主体的永久身份、类型、群演属性、修订与对象版本；无主体返回空数组。素材族的 `materialUsageScopes[]` 保留逐条用途及其原范围，不拼入旧 `episodeIds`、`sceneIds` 或 `shotIds` 数组。目录关系明确实际 owner/member 方向；客户端筛选应匹配同一条用途，不对不配对数组取组合。陈旧用途和历史范围保持原引用，完整路径缺失则展示 UNKNOWN。
