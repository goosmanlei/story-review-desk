# 站点图标配置与恢复

“系统管理 → 系统与 AI”中的站点图标用于浏览器标签页和收藏夹。左侧“当前图标”显示已保存结果，右侧“待保存预览”显示本次选择。选择已有图标，或上传新文件，再点页面底部“保存配置”；保存成功并回读后当前页面立即应用，其他已打开页面刷新后应用。点“恢复默认图标”再保存，恢复系统自带的书页图标。重启服务不会丢失已保存配置；收藏夹自身的缓存刷新由浏览器决定。

上传成功只登记文件并改变预览，不表示配置已应用。取消文件选择不改变已有选择；超限、无效文件或上传失败保留原选择及评论润色输入。图标与评论润色共享一次配置保存、版本检查和草稿；切换配置子页或刷新可恢复本标签的草稿。版本冲突不自动覆盖最新配置，保存响应不明时先回读核实，不能把重试当作成功。成功保存后有持续结果提示，新输入会另标为尚未保存。

支持至多 256 KiB 的静态 SVG、8 位 RGB/RGBA 非交错 PNG（至多 1024×1024），以及内部图像为 PNG 的 ICO。SVG 只接受基本形状，不支持脚本、外链、字体、样式表或滤镜。已保存的图标损坏或缺失时，页面临时显示默认图标，系统与 AI 配置明确提示故障并保留原文件名；阅读与配置修复入口继续可用。临时显示不修改配置或事件，须明确选择有效图标或清空后保存。

上传后使用实例的 `export/assets/` 逻辑路径，文件名包含内容 SHA-256；启用 OSS 时原件及显示预览上传、完整回读后登记资源目录，未配置云存储的实例保留本地文件。上传只是准备文件，保存配置才采用它。选择器只提供可验证的受管文件。替换／清空不删除原件，避免破坏历史引用；这项功能不提供资源删除。

公开字段为 `SYSTEM.site_favicon`，值是 `export/assets/` 下的单个文件名，空字符串表示默认。禁止 URL、绝对路径、目录穿越和符号链接。保存沿用 `expected_version` 检查及配置事件；旧 Schema 1—3 读取时补充空值，首次保存写为 Schema 5，不改其他配置。API 与 CLI 同样验证素材。

```json
{"expected_version":4,"updates":{"site_favicon":"lantern-home-favicon.svg"}}
```

`GET /favicon.ico` 按当前配置返回实际图像及对应 MIME 类型，已保存图标不可用时仍返回 503；名字兼容浏览器默认请求，内容可以是 SVG、PNG 或 ICO。页面链接使用具体 `/assets/<文件名>` 或 `/default-favicon.svg`，并带内容 SHA-256 查询参数；更新时替换图标节点，避免 Chrome 清空后重新设置再刷新仍显示旧图标。响应不缓存，以支持替换。`POST /api/favicon` 接受 `{name,data}`，其中 `data` 是 Base64 文件内容，返回受管文件名。配置接口另外返回图标元数据和可选受管文件名；图标不可用时 `favicon` 指向临时默认图标，`favicon_error` 给出原因，`values` 仍是原配置。保存与导出／恢复继续严格验证图标。

执行 `export` 后，当前图标进入完整恢复范围。云实例按 [Schema 16](resources.md) 保存准确对象版本与校验信息，Git 只提交轻量配置和目录；母版、原件及派生留在受管资源存储。旧完整本地包仍携带实际图标文件。恢复前准备相应导出与实例内容，再执行 `restore`；图标缺失、校验不符或未被目录覆盖时，拒绝写入空实例。历史配置事件保持原样，恢复已采用的图标不依赖生成平台或临时链接。

自动回归入口：`PYTHONPATH=. python3 -m unittest discover -s tests -v`。实例的浏览器显示、正式运行版本及阻断项应在该实例交付记录中核验，接口成功不等于标签栏显示已验收。
