# 当前制作内容与生成候选

故事资料、结构、小说、剧本继续使用不可变版本。制作域的实体、独立状态、关系、视听集场镜、输入锁和素材需求使用稳定身份与一份当前正文。改稿、改参考、改组成均原地更新，不新建制作版本或逐级推进父对象。不同剧情状态仍是不同对象，编号不复用。

## 当前稿与提交快照

`production_current_records` 保存稳定正文地址、`edit_token` 并发计数和内容摘要。API 的 `revision_id` 对制作域只充当地址，不表示旧全文可以恢复；更新必须核对 `expected_content:{edit_token,content_sha256}`。故事和方法记录仍保留原不可变语义。

素材需求的 `generation` 是唯一当前方案，包含目的、方法、模型、参数、完整 Prompt、有序输入、输出规格及必要检查项。第一次生成后仍可原地修改。只有实际对外提交才在 `production_submissions` 固定本次完整请求、需求、准确故事和方法依据、实际输入内容及文件哈希、组成、裁切／时间范围。候选的阅读不依赖整棵旧制作树；历史缺失保持缺口，不用今天的方案补写。

`POST /api/production/submit` 在事务中核对准备包、当前目标和并发标记，持久化唯一操作／调用身份后返回。调用工具收到成功回执后才可向生成平台提交；`already_applied:true` 表示只能查询原调用，不能再次付费发送。参数或参考变化必须使用新的操作身份。

`POST /api/production/result` 记录原调用的轮询、回调与结果。未知、失败且没有原件时不产生候选；迟到原件仍归原提交。回调重放、下载重试和同次多文件只形成一个候选。同样参数的另一次真实调用形成另一个候选。真实请求、响应、费用及原件事实不得改写；共享调用保留实际需求归属，不重复计算费用。

上传、外部制作和可编辑工程保留真实来源与组成，不虚构模型调用。多个 ASSET 元数据修订若属于同一调用及原件，会合为一个候选；不同实际调用不能仅因相同哈希合并。

## 阅读、选择与复用

共用卡只切换“当前方案”和实际候选，参数、完整 Prompt、纯参考列表直接显示。候选始终使用提交快照；当前方案按当前正文显示。阅读候选不改变所选生成输入或采用。实体与独立状态、集场镜不再提供制作版本选择。

`POST /api/production/reuse-candidate` 将准确候选方案复制为当前需求的起点，核对候选归属、完整原方案、所有准确输入及当前并发标记。缺失、过时或冲突直接拒绝，不补最新文件，不触发生成，原候选不变。后续改稿沿现有制作方法执行。

旧地址由 `production_legacy_links` 最小映射到真实候选、原意见或明确退役提示。仅有旧制作稿的地址不能冒充当前内容。旧版号映射不再承担新的业务版本。故事版本链接不变。

## 意见与方法事实

当前内容意见保存原摘录、原位置、对象身份和当时内容摘要。写入携带 `expected_edit_token`；正文已变则拒绝并保留草稿。修改后不能按相似文字重新高亮。候选意见固定候选、真实组成及图像区域／音频时间。

`comment-handling-v1` 保留实际整改说明及必要改后局部摘录；原意见提供改前摘录。再次改稿时明确当时回应与今天正文不同，不伪造完整旧稿或第二份评论状态。浏览器草稿按标签页、准确对象、候选及当前并发标记隔离，切卡和刷新可恢复；旧标记草稿保留原摘录，不自动挂到新文字。

新制作方法记录只保存实际所用方法、输入摘要、执行事实、产物摘要及结果指向，不能在 NOTE／method.artifact 中复制每次完整制作稿。完整工作检查点留在隔离工作区，恢复用途结束后清理。过去已经发生的方法执行保持原样。

## 迁移、导出和恢复

`production_current_migration` 的准确清单绑定当前头和全部旧制作行摘要。先提取真实调用快照、原件组成及意见／回应摘录，再删除旧制作全文、轮次、方案版本及专属索引，清理失去引用的 `material_content` 节点。迁移在一个事务内复核基线，失败回滚；同清单重放幂等，旧基线拒绝。当前模型不会通过旧导入入口重新写出版本链。

Schema 13 完整导出包含单份当前制作正文、提交快照、真实候选、最小旧链接映射、意见／回应摘录，以及原有故事版本、方法、配置、真实调用及有效文件。导出校验全部正文和故事图文引用的原件；恢复仅进入空实例，并验证配置、哈希、准确依赖及已退役模型。完整导出不能包含可还原整棵旧制作树的隐蔽副本。发布后的常规恢复拒绝旧制作格式；迁移备份只用于明确的灾难恢复窗口，不能作为业务版本或覆盖较新活库。

受管 JSON 请求与回执仍可沿 `material_archives` 恢复原字节，媒体原件不转换。实际发布、停机窗口、恢复权限及本机备份解除条件由实例发布器负责。

## 验证

`tests/test_production_current.py` 覆盖原地更新、提交后改稿、回调幂等、失败与迟到结果、候选复用、局部评论、方法压缩及两轮空实例恢复。既有旧格式测试用于迁移输入的兼容性，不能作为继续写旧模型的使用指导。实例交付还须验证真实原件、准确范围和 Chrome 当前稿／候选／意见路径，自动检查不证明媒体质量。
