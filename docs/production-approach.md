# 制作思路：实例方法文档

首页工作区为 `production.approach`。无参数首页默认打开实例文档的第一子页；格式版本 2 可按实例需要排列“故事创作”“生产制作”和独立方法子页。`?workspace=production.approach&tab=materials` 直接进入“生产制作”。其他子页使用同一 `tab=<id>` 路由，名称与顺序来自实例内容，不另建工作区。未知子页回到第一项。显示名称改为“生产制作”后，仍保留 `materials` 路由 ID 与章节锚点，原链接继续有效。Tab 支持刷新、浏览器前进后退及左右方向键、Home/End。旧 `?workspace=current` 只在前端映射到新页，不再登记旧工作区或运行旧统计。

各子页均以左侧常驻目录组织章节，沿用故事创作页的浅色阅读栏、红色选中边线与章节高亮。目录随正文滚动更新当前位置；条目保留原生锚点链接，章节可直接访问、刷新恢复并使用浏览器前进／后退。宽度不超过 1000 像素时目录移到正文上方，常驻并可横向滚动，定位时避开目录与站点顶栏。该高亮仅为当前阅读位置，不产生进度数据。窄屏横向目录由读者自行滚动，高亮更新不抢回目录位置；目录滚动不当作正文阅读进度。刷新／往返恢复位置后，仅在目标章节标题部分落入固定栏遮挡区时重新对齐；已读到章节深处的保存位置继续保留。

## 查方法后继续工作

从制作现场临时查方法，普通点击方法正文中的站内方法链接或目录锚点，沿现有页面导航继续阅读。返回“生产制作”恢复本标签页该历史条目的准确子页、集场修订、筛选、页码与阅读位置；主动关闭的素材卡保持关闭。管理列表重新打开时以返回 URL 的搜索和筛选为准，不能沿用另一次访问的已挂载列表。

返回路线与必要位置存在浏览器当前历史条目中，刷新和前进／后退使用该次访问的现场，并校验站点、实例和发布身份。没有写入全站共享的工作记忆。直接打开方法 URL，或用 Command/Ctrl、中键及新标签打开干净方法链接时，没有原现场可恢复，使用默认入口；原标签保持原工作。明确作品／版本链接继续打开所指目标，外部来源保留原生新标签行为。准确修订不可用时沿既有失效提示，不以新版本代替。

导航只恢复阅读现场，不保存评论、不采纳、不重认原件，也不改变草稿的准确归属。回归见 `tests/method_return.test.cjs`；真实实例验证由故事项目的任务记录维护。

## 内容与系统的分工

系统提供只读加载、文字、目录、顺序流程、响应式表格、原样代码块、链接及明确声明的本地媒体展示。实例的方法、具体例子与引用保存在实例根目录的 `content/production-approach.json`，由 Git 管理，不写业务数据库，不生成对象修订、配置事件或进度记录。`GET /api/production-approach` 每次读取该文件；前端在一次页面会话中复用内容，修改文件后刷新页面即可看到更新。

文件可省略：接口返回 `null`，页面说明未提供方法，既有资料和审阅功能继续可用。文件格式错误时该接口返回 503，页面明确显示错误；不会阻止故事、结构、配置或评论加载。客户端只按文本节点渲染内容，链接只接受 HTTPS 或同源 `/?...` 工作区入口，不能注入 HTML 或可执行 URL。

最小格式如下。文档 `schema_version` 只描述阅读文档格式，与数据库或业务导出 Schema 无关。

```json
{
  "schema_version": 1,
  "tabs": [
    {"id": "story", "label": "故事创作", "title": "本故事的创作方法", "lead": "读者导语", "sections": []},
    {"id": "materials", "label": "生产制作", "title": "本故事的制作方案", "lead": "实现边界", "sections": []}
  ]
}
```

每个 `sections` 条目必须有唯一的字母／数字／连字符 `id` 和 `title`，可包含 `paragraphs`（文本数组）、`flow`（`title,text` 数组）、`table`（`columns` 与等长 `rows`）、`note` 和 `links`（`label,href` 数组）。可选的链接 `workspace` 表示仅在该工作区已经实现时显示入口，避免实例文档伪装未开放功能。正文应自行说明作品是否待审阅、哪些生产能力仍为方案，不能从导航开放状态推断作品已经生成或接受。

### 格式版本 2：完整独立方法页

`schema_version: 2` 保留 `story`、`materials` 两个 ID，允许实例决定它们及其他子页的顺序。所有 `id` 使用唯一的小写字母、数字和连字符。所有子页沿用 `label`、`title`、`lead`、`sections`；锚点格式为 `#approach-<tab-id>-<section-id>`。版本 1 仍要求 `story`、`materials` 两项及原顺序，旧文档继续原样支持。

新版章节可使用按阅读顺序排列的 `blocks`，与原有的 `paragraphs/flow/table/note/links` 二选一，避免重复正文。每种块只承担显示：

| type | 内容字段 | 显示行为 |
| --- | --- | --- |
| paragraph | text | 段落 |
| heading | level 为 3 或 4，text，可选 id | 章节内两级小标题；有 id 时支持精确直达 |
| list | ordered 布尔值，items 字符串数组 | 有序或无序列表 |
| code | text，可选 language | 保留空格、换行和原文；窄屏换行，不解析其中的标记 |
| table | columns，等宽 rows | 桌面表格；窄屏按行显示且保留列标签 |
| media | kind、file、caption、sha256；图像和视频另需 width、height | 明确声明的本地图像、音频或视频，说明文字及原生播放控件 |

段落、列表、小标题和表格正文只识别反引号行内代码、双星号加粗及显式 Markdown 链接，其他内容按文字显示。系统不解析 HTML、iframe 或远程内容嵌入；正文链接须由读者点击才打开。

小标题的可选 `id` 使用小写字母、数字和连字符，须与同一子页的全部章节和小标题 ID 互不重复。链接仍使用 `#approach-<tab-id>-<id>`，点击、直接打开、刷新和历史往返沿用共同的阅读位置恢复，不建立第二套导航状态。

媒体块的共同字段为 `type: media`、`kind: image|audio|video`、`file`、非空 `caption` 和 64 位小写十六进制 `sha256`。图像和视频还必须提供原件实际尺寸 `width`、`height`（1—32768 的整数，SVG 使用声明的画布尺寸），提前保留画面占位，避免加载媒体时改变阅读位置；音频不接受尺寸字段。不接受其他字段。`file` 必须是以小写字母或数字开头、仅含小写字母／数字／点／连字符／下划线的文件名；图片允许 PNG/JPG/JPEG/WebP/SVG，视频允许 MP4/WebM，音频允许 MP3/WAV，扩展名须与 kind 匹配。原件放在实例 `content/production-approach-assets/`。例如 `{"type":"media","kind":"video","file":"demo.mp4","caption":"动作示例","sha256":"准确原件摘要","width":1280,"height":720}`，示例摘要和尺寸必须替换为实际值。

SVG 只接受 UTF-8 编码、SVG 命名空间内静态解释图的形状、文字、分组及白名单属性中的本地标记引用，不接受声明、处理指令、脚本、事件、外部引用、样式或嵌入内容。服务读取原件并完成摘要核对后才做这一校验；SVG 不以内联 HTML 插入页面。图像可通过点击或键盘打开共用放大窗口，在适应窗口与原始尺寸之间切换；原始尺寸允许横纵滚动，便于窄屏阅读细节。方法图查看不受其他工作区尚未完成的圈选状态影响。媒体加载失败会显示具体恢复提示，正文仍可阅读。

`GET /approach-media/<file>` 仅提供方法 JSON 中声明且摘要一致的普通本地文件，支持 Range 播放；拒绝路径跳转、符号链接、未声明文件及摘要不符的文件。研究目录和任意外部地址不能成为媒体来源。图片按需加载，音视频只预载元数据、不自动播放；播放另一条时暂停当前条，离开工作区沿用共同的暂停规则。恢复或发布时同时冻结 JSON 与其声明的原件，服务挂载须只读；文件与正文失配时先修复准确交付，不能绕过摘要检查。

实例可以用可选的 `source` 保存权威稿的相对路径和摘要。系统将它视为实例元数据，不读取该路径、不执行生成脚本、不校验故事特有规则。若实例有 Markdown 等权威稿，其生成和一致性校验由实例维护，不能手工维护两份正文。方法研究、模型选型和付费调用均不属于审阅台。

恢复实例时随代码检出 `config/` 和 `content/`，业务资料仍通过 `export/` 在空库恢复。方法文件不加入业务导出清单，不改变既有 Schema；仅有 `export/` 的备份并不包含这份 Git 文档。完整实例交付须同时保留实例仓库与业务导出。更新方法不需要数据库迁移。
