# 审阅台使用与维护

审阅台是独立的创作工作空间，一部故事绑定一个项目实例。已发布数据库修订是业务权威，网页、Codex 与制作工具共享永久身份、版本和精确依据；chatgpt.site 仅为功能 Review 的只读镜像。

## 开始与推进

新故事使用独立项目、干净软件与空 PostgreSQL 实例，不复制另一故事数据库：

    node review-software/scripts/instance-project-create.mjs --project /新项目目录 --title 故事名

以该项目根目录作为 Codex 工作目录。在系统管理确认规则，在故事创作显式导入来源，再通过 Codex 按精确 revision/SHA 整理主体、空间与素材建议。建议在所属模块保存草稿、预览和确认，不要求全剧设定齐备才开始作者稿。导入不证明完成原图、音频、视频观察或权利核验；未知保持 UNKNOWN。

## 模块职责

| 模块 | 维护内容 |
| --- | --- |
| 当前工作 | 同一读取事务汇总工作链、阶段、阻塞与下一步，不另存进度 |
| 故事创作 | 来源、结构、分集卷宗、正文、评论与叙事判断 |
| 故事设定 | 永久主体、空间与关系，见[故事设定](story-settings.md) |
| 素材管理 | 需求、生产资料、参考、实际版本、权利与素材审阅 |
| 全剧制作 | 镜头制作（六步骤）、场景剪辑、分集成片 |
| 系统管理 | 规则初始化、[配置](system-configuration.md)、数据与运行、多 Agent 协作 |

模块状态、当前工作与技术附录共用模块目录和事件投影。正式范围未冻结时显示 UNKNOWN；库存、候选和准备稿不冒充正式分母。全剧导出保持 PROJECT 范围，不能因选中某集而缩小。

## Codex 与审阅

本地 Codex 沿用已有 SDK／CLI 认证与计费，其他 AI API 通过配置的环境变量名读取 API_KEY。密钥不写入配置正文、Git 或导出。长来源按目录检索、精确版本分块读取，不静默截断；搜索命中不等于正文已读。协作模式、具体动作授权与媒体生成授权独立。

已关闭评论默认每页 20 条摘要，展开才读取完整圈选、意见及处理说明；统一检索覆盖全部历史并按永久评论身份去重。历史只读，当前普通关闭记录的重新打开仍校验原权限和精确锚点。筛选与未提交判断再次点击可取消；导航、版本选择及已提交历史不据此撤销。

本集六项输入、正式放行与主机受控源同步独立。同步后，各场独立提交 SceneCoverage 与 ShotPlanSet，不等待其他集，也不自动采用全剧。V2 镜头设计冻结完整需求、节拍及设定条件；缺少实际素材时可以设计采用，但逐镜输入仍须锁定 familyId、versionId、SHA、空间、Prompt 和本轮授权，设计采用不表示可生成。V1 冻结规则及历史保持。

素材卡统一展示产物及版本、审阅、生产资料与用途。AI 辅助审阅和询问助手与正式提交同排，但仅产生建议。实际版本、权利和输入变化只影响依赖它们的下游。

仅叙事说明或适用场次追加引发的失效，可由本地 Codex 按[生产兼容确认](domain-production-compatibility.md)逐版本核验。旧产物兼容不等于新增场景采用；原审阅、版本、执行和媒体历史保留。

## 多 Agent 协作状态

系统管理的第四个页签“多 Agent 协作”可用 `?view=system&systemTab=orchestration` 定位。页面仅 GET 当前显式实例，展示模式、四类 Worker、正在处理、队列、完成历史和待用户决策；完成历史每页 20 项，包含取消、被替代和已结束的失败质检。运行中实际模型与推理强度只取执行记录，未记录不从默认设置推断。任务需要调整时通过项目主会话处理。

后台运行状态来自宿主写入现有 `runtime/locks` 共享挂载的白名单心跳，绑定实例与运行期，30 秒内有效；缺失、过期或旧版本后台显示 UNKNOWN，不以模式 ACTIVE 或容器中的 PID 代替运行事实。暂停、阻塞和收尾仍更新心跳；显示心跳不写任务账本，也不改变调度策略。运行数来自账本登记；未知结果和取消中的执行继续占位，分别说明可用名额与是否可派发。

有运行中或排队任务时每 5 秒自动刷新，最多 60 次；离开页签、页面隐藏或读取失败停止，手动刷新重置次数。API 只返回显示所需的白名单字段，排除完整输入、凭据、执行路径、线程与原始错误；Hosted 在读取实例前拒绝，页面仅提示本地专属。此投影不进入故事业务进度或公开快照。

## 备份、导入与恢复

数据与运行提供实例核验、完整备份、下载、文件或项目内目录导入、隔离恢复，以及配置模板转移。任务排队不等于完成，结果未知不自动重试。

完整备份含业务版本、不可变历史和受管媒体，可能包含私有创作会话；不含模型凭据及活跃运行缓存。便携文件为 .review-backup.gz，流式解包核对路径、顺序、大小、SHA、数据库结构及媒体登记。损坏、截断和其他故事的文件不能进入本实例可恢复列表。只读导出排除原始录音、私有助手记录及试制媒体，不能用于恢复。

恢复只写入新目录与独立卷，保留故事身份、重建运行期，不覆盖原实例或重放旧任务。核对恢复证明后，由本地 Codex 显式切换运行绑定；原实例保留用于回滚。切换后重新核验实际端口、实例、发布及数据指纹。

配置模板仅转移通用规则；导入保存为草稿，回系统配置预览并发布，不覆盖已有未发布草稿或冻结对象。技术附录实时显示职责、版本水位、计数、共用阶段和接口；原始文档、事件、有效媒体、权利及必要恢复基线不作为缓存删除。细节见[实例隔离](instance-isolation.md)。
