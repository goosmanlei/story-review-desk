# 评论能力核对清单（旧审阅台 → 本项目 V1）

对照来源：本机历史 `story-review-desk/web/app/story-comments.tsx`、`closed-comment-history.tsx` 和 `tests/entity-comments.ui.mjs`，2026-09-21 只读核对。历史目录与本项目无代码或数据继承关系。

| 旧版可见行为 | 新版 V1 | 验证方式 |
| --- | --- | --- |
| 圈选文本，就近出现“添加评论” | 同一交互；可跨连续正文块 | 浏览器圈选、服务端原文 quote 校验 |
| 草稿取消或收起后不丢失 | 未提交新评论按资料与精确锚点保存在本机浏览器 | 浏览器重新圈选同一文字核对 |
| 评论绑定精确文本与上下文 | 稳定对象 ID、精确修订 ID、正文块 ID、起止字符、quote；资料仍兼容 source_id；服务端拒绝错配 | 单测含跨块、Unicode 罕字与对象换版后旧评论不漂移 |
| 提交、编辑、关闭、重新打开 | 四种操作及版本并发保护 | 浏览器与单测 |
| 正文高亮、评论面板定位原圈选 | 高亮、点标记开评论、从评论滚回原文 | 浏览器 |
| 评论浮窗快捷关闭 | Esc 或点击浮窗外收起；浮窗内操作不触发关闭，收起后可重新打开未保存的编辑状态 | 2026-09-22 本机浏览器验证 |
| 未关闭评论计数、已关闭历史分页 | 按资料计数，历史每次显示 20 条 | 浏览器/代码 |
| 刷新或重启仍保留，关闭记录保留事件 | SQLite 本机持久化；导出包括全部评论与事件 | 重启/恢复验收 |
| 过期评论不静默移位 | 正文 ID 不可原地修改；导入/恢复时重验 quote | 冲突单测 |
| AI 润色建议先预览再应用草稿 | 先展示背景、创作阶段、邻近原文及各版本资料等参考信息；确认后调用 OpenAI Responses API；建议仅供手动采用，永不自动提交 | 浏览器、上下文与请求测试；未配置密钥时明确报错 |

结论：通用评论生命周期和对象修订级锚点按新结构重建；当前浏览器资料页只是首个对象适配器。旧版评论还覆盖分集设计和实体，这些创作工作区本次仍未开放；它们可复用同一评论 API、持久化和锚点校验规则。
