# 评论能力与回归清单

跨版本意见、作者回应、准确改动与人工关闭的关系见 [历史意见复核](comment-review.md)。

本文供实现和验收评论能力的开发者使用，描述当前行为与检查入口；实际实例、视口、操作和浏览器结果由对应故事仓库保存。初始交互参考为本机历史 `story-review-desk/web/app/story-comments.tsx`、`closed-comment-history.tsx` 和 `tests/entity-comments.ui.mjs`，于 2026-09-21 只读核对；历史目录与本项目无代码或数据继承关系。

| 可见行为 | 当前契约 | 验证方式 |
| --- | --- | --- |
| 圈选文本，就近出现“添加评论” | 双击、拖选、反向及跨段选区共用处理；在正文外松手仍触发，按钮跟随可见选区末端；模态框内移入当前叠层，关闭后恢复上层或正文归属，避免按钮在弹窗外被浏览器阻断；清除选区或切换工作区时收起 | 隔离浏览器回归及真实鼠标拖选；服务端原文 quote 校验 |
| 草稿收起后不丢失，取消时放弃 | 收起草稿等同关闭面板，保留当前精确圈选和编辑内容；取消按钮或输入框内 Esc 在本机清理成功后放弃本次新评论／编辑草稿，已保存评论不变 | 实际编辑器回调测试及隔离浏览器收起／重开核对 |
| 评论绑定精确文本与上下文 | 稳定对象 ID、精确修订 ID、正文块 ID、起止字符、quote；资料仍兼容 source_id；服务端拒绝错配 | 单测含跨块、Unicode 罕字与对象换版后旧评论不漂移 |
| 提交、编辑、关闭、重新打开 | 四种操作及版本并发保护 | 浏览器与单测 |
| 正文高亮、评论面板定位原圈选 | 高亮、点标记开评论、从评论滚回精确圈选；长章或长结构块定位到所选原文。宽度不足1200像素时，采编、结构及剧本找到有效目标后收起遮挡正文的评论，并把焦点返回现有评论按钮；剧本引用结尾沿同一规则。失效引用保留评论面板 | 隔离浏览器检查准确引用可见、键盘返回与草稿保留；四个断点及失效修订／目标由事件测试核对 |
| 评论浮窗快捷关闭 | 输入框外 Esc 或点击浮窗外收起，草稿保留；输入框内 Esc 执行取消并放弃内容，面板保持打开 | 快捷键与原有圈选／集场隔离回归 |
| 桌面故事正文与评论同时可读 | 宽度至少1200像素时，采编、结构、剧本的顶层评论打开后为正文预留空间；开关按可见原文保持位置。窄屏故事阅读沿用浮层 | 同一准确引用开关前后核对换行、滚动位置与遮挡；回归三个阅读页、草稿与窄屏 |
| 素材弹窗评论与返回 | 宽度至少1200像素时评论在正文旁展开；较窄时评论临时覆盖正文区域，保留弹窗标题和关闭按钮。收起及定位返回原正文，播放器与草稿不重建；关闭嵌套弹窗恢复父评论与焦点 | 实际验证两个滚动区域、准确媒体和时间、关闭按钮可点击、窄屏定位及键盘焦点；核对外层评论原本打开和收起两种情况 |
| 未关闭评论计数、已关闭历史分页 | 按资料计数，历史每次显示 20 条 | 浏览器/代码 |
| 刷新或重启仍保留，关闭记录保留事件 | SQLite 本机持久化；导出包括全部评论与事件 | 重启/恢复验收 |
| 过期评论不静默移位 | 正文 ID 不可原地修改；导入/恢复时重验 quote | 冲突单测 |
| AI 润色建议先预览再应用草稿 | 展示准确对象、完整圈选、当前意见与必要邻文，历史比较和背景按需要加入；调用前复核同一参考快照；建议仅供手动采用，永不自动提交 | 浏览器、上下文与请求测试；未配置密钥时明确报错 |

结论：故事采编、故事结构、分集剧本及三个制作入口复用同一评论面板。分集按版本下的独立 EPISODE 对象及精确修订隔离；制作评论按实体、状态、素材、镜头等对象的确切修订隔离。

没有准确资料、结构稿、剧本分集或制作对象修订时，评论入口隐藏，空评论面板关闭。有准确对象但零评论时仍可圈选并打开面板。资料或扩写方向尚未登记时，页面说明等待后台准备；方向已选而完整结构稿尚未发布时，只显示已选方向与等待稿件，不展示空版本控件。

“收起草稿”保留本次页面中的精确文字、整图或区域锚点、编辑身份与未确认提交，点击既有评论入口即可继续。同一准确草稿重开保留现有输入框；从局部评论切回全部评论需要重绘时，仍保留当前输入与准确素材版本上下文，避免本机存储失败后被旧存储值覆盖。收起本身不是跨页草稿管理器；制作卡片另按准确修订、素材标识及方案版本保存本页草稿上下文，切回时恢复，不能将旧锚点带到另一个版本。旧草稿若已经失去锚点，不能仅凭相似文字自动找回。取消清理失败时保留当前编辑器并明确说明未完成；多个本机键可能已部分删除，不能保证刷新后仍恢复全部输入。资料图像定位同时核对当前资料、准确修订及原件，只在本资料阅读区查找；不存在或已失效的原图仍保留原错误说明，不跳到同名的其他工作区图像。资料图像新建区域也只使用当前资料原件；手势开始后切页、切资料、换修订或重绘到另一草稿时，迟到的松手事件不改变新上下文。资料圈选不依赖是否已有结构稿。

## 正文与完整素材卡弹窗

实体管理、素材管理正文和逐镜页面打开的“实体大卡”弹窗复用 `renderUnifiedCard`。同一准确内容的文字、整图、区域和音视频时间评论，都使用原评论面板、锚点与提交接口；弹窗不另建评论存储。完整大卡中的实体采纳操作仍属于实体准确范围，评论不会自动改变采纳或镜头采用。剧情依据、参考输入、原方案和放大图弹窗各自保留原能力，不能因外壳一致就默认都可采纳或圈选评论，详见 [素材卡与关系契约](materials-and-relationships.md#页面与评论)。

| 场景 | 必须核对的结果 |
| --- | --- |
| 正文与完整大卡弹窗审阅同一素材 | 原件、方案版本、候选、实际生成记录及评论目标一致；新建、编辑、关闭、重开和定位仍绑定准确修订。 |
| 素材版本、候选或文件组成往返 | 不把别的候选实际调用、采用范围或草稿锚点带入当前原件；旧评论仍可定位原文件。错误版本或候选明确失败，不回退到最新。 |
| 从预览定位原件意见 | 一次恢复意见所属的准确修订、候选及原件组成，按文件标识核对，时间相同也不能代替；时间定位暂停先前媒体并恢复完整选段及起点，图像恢复原圈选。 |
| 提交前切组成及定位中保留草稿 | 提交继续使用圈选时的准确文件与范围；编辑器的“评论对象”显示该组成。定位另一条意见不迁移草稿；方案版本与旧轮次映射往返后仍回到各自准确上下文。 |
| 文件或圈选不能恢复 | 缺失修订、组成、文件或越界范围明确说明，保留评论及草稿，不替换文件或裁短选段；文件实际读取失败显示原因，失败后仍可返回继续审阅。 |
| 同来源需求切换 | 每项需求保留各自准确版本、候选、评论锚点及草稿；切换后评论不串到兄弟需求，返回后恢复原目标。 |
| 从镜头打开素材后关闭、Esc 或后退 | 恢复外层镜头／素材、草稿及焦点，停止弹窗媒体；只关闭最上层。X／Esc 关闭不能留下额外同页历史项，弹窗内实体刷新也不清掉历史标记。 |
| 弹窗读取未完成便关闭或切页 | 迟到响应不恢复弹窗，不替换当前对象、评论面板归属或草稿。实体筛选的旧响应同样不能恢复已离开的实体。 |
| 实体切换与关系弹窗往返 | 顶层实体读取成功后，列表视觉选中与 aria-pressed 同步到当前实体；准确旧版仍选中所属实体。弹窗内刷新不改外层列表，跨越弹窗打开或关闭的迟到响应不覆盖新的阅读上下文。 |
| 逐镜设计与镜头制作 | 每镜左侧内容、右侧本镜素材保持对应；共享素材来自明确挂载或适用关系。提示词参考打开准确输入，不因点击引用改变外层评论目标。 |
| 窄屏 | 大卡和逐镜行上下排列，标题、版本、候选与评论控件仍可操作；目录和正文可读，长正文不被高度上限截断或与页脚重叠。 |

以上是验收要求，不是浏览器通过记录。自动契约由 `ui_unification_compatibility.test.cjs`、`ui_unification_requirements.test.cjs`、`material_navigation.test.cjs`、`entity_material_navigation.test.cjs` 及相关评论测试覆盖；实际手势与布局在隔离实例操作后，由故事证据记录。

组成定位另由 `comment_location.test.cjs`、`entity_review.test.cjs` 和 `media_location.test.cjs` 检查准确文件／修订／候选、状态历史、草稿及迟到载入。实体入口的历史状态可能只随素材的 `associated_states` 返回；只恢复与该素材准确引用一致的状态，不能借用同对象的当前状态。定位查找仅在当前阅读区或最上层完整卡片中进行。真实浏览器须走“播放原件 → 圈选 → 写意见 → 切预览 → 提交 → 定位”，再检查同组成、关闭重开、实体入口、连续点不同意见、慢载入及读取失败；缺乏视频或多候选样例时由实例记录限制，不把自动检查称为业务实践。

## 评论输入与快捷键

润色与参考预览绑定发起请求时的准确对象、修订、草稿键及文字。切页、换修订或修改意见后，旧结果不覆盖新草稿；同一意见重绘建议或错误时，保留当前输入框的原始文字与选区，避免本机存储写入失败后退回旧文字。SOURCE 参考请求若带明确修订，服务端按该修订校验，拒绝失效或错配引用；不带修订的旧请求仍使用当前资料。建议只供明确采用到草稿，不自动提交评论。

故事采编、故事结构（文字、整图、区域及整体意见）和剧本分集使用共用评论编辑器。只有评论输入框聚焦时，⌘+Enter 才执行“提交评论／保存修改”，Esc 才执行“取消本次评论／取消编辑”。取消成功会删除本次浏览器草稿，放弃未提交的新内容或编辑；重新打开同一引用时，新评论为空，编辑显示最后保存的正文，已保存评论和历史不变。Esc 取消后面板保持打开。普通 Enter 继续换行，中文输入法组合期间不提交、不取消，也不把 Esc 传给面板关闭操作。

输入框外沿用现有 Esc 行为：收起评论面板并保留草稿；大图中的 Esc 只关闭大图。点击“收起草稿”、面板关闭按钮或面板外部也保留未提交内容。配置及其他普通输入框不接入评论快捷键。

空白正文不能提交；保存请求期间输入框只读，提交、取消和草稿操作暂时禁用，按钮与快捷键均不能重复发出请求。请求失败会保留草稿、显示错误并解除限制，可以修正后重试。已经发出的请求不提供撤销，取消应在提交前执行。

新评论发送前先在本机保存准确请求与创建 ID。服务器已保存但响应丢失时，原样重试复用同一 ID；刷新后回到相同修订、锚点和素材轮次重开草稿，仍可确认该次保存。断流、5xx 或成功响应正文不完整时说明结果尚未确认；明确 400／409 则说明提交被拒绝，保留原草稿、准确范围与请求 ID，不自动改投新轮。每次尝试的本机状态独立更新，另一标签同 ID 重试后不沿用旧拒绝。修改正文、锚点或目标属于新提交；不按相似文字全局去重。取消只删除本机恢复记录，不能撤销后台已保存的评论。

本机存储失败时保留当前输入框及准确版本上下文并明确提示；正文或准确提交身份未持久保存时不发送请求。收到保存成功后，本机清理失败仍明确说明已保存，保留编辑器与原请求身份；原样再次保存只重试清理，不重复发送，已有评论编辑同样处理。成功标记无法持久化时仅在当前页面保留，并提示刷新限制；原请求 ID 不因此丢弃。清理完成后撤下编辑器，即使评论列表没有变化也不残留恢复提示。迟到成功只清理自己仍未变化的草稿，不能清掉另一页、轮次或标签页后来写入的内容。应验证断响应、明确冲突、部分清理失败、同 ID 恢复及旧版本编辑；测试函数不能只用重绘计数替代实际输入检查。

后续新增评论区必须复用 `app.js` 的 `bindCommentEditorShortcuts(textarea, {submit, cancel})`，传入实际提交／取消按钮，由同一按钮处理验证、提交锁和取消语义；不要再注册独立的全局快捷键。该函数通过按钮 `.click()` 执行现有操作，遵循输入框只读／禁用及按钮禁用状态，屏蔽按住按键产生的重复事件。现有共用编辑器自动接入，无需按工作区复制实现。

在仓库根目录运行：

```bash
PYTHONPATH=.:tests python3 tests/screenplay_server.py --port 8796 --evidence /tmp/comment-shortcut-browser.json
```

浏览器打开 `/comment-shortcut-tests`，点击“运行快捷键检查”，覆盖三类页面新增／编辑、按键与按钮结果一致、取消删除草稿、输入框外 Esc、普通 Enter 事件、组合输入保护、空内容、只读／禁用、按住重复、延迟请求、版本冲突恢复、关闭／重开、独立新编辑器接入、普通输入框和大图。仅使用临时资料和测试评论；组合输入以事件模拟，不等同于操作系统中文输入法实测。选择“真实键盘页面”并点击“准备真实键盘草稿”，可在三类页面另行核对真实 Enter 换行、⌘+Enter 新增／保存和 Esc 取消。每轮从新启动的夹具执行；只清理该测试端口的浏览器存储，不涉及正式入口草稿。

## 分集剧本回归

`PYTHONPATH=.:tests python3 tests/screenplay_server.py --port 8793 --evidence /tmp/screenplay-browser.json` 启动一次性双版本、双分集测试资料，浏览器打开 `/screenplay-tests` 点击“运行隔离检查”。检查默认最新版本、统一顶部页签、纯版号标签、原序集场目录、选集默认首场及直达链接，概览不重复正文、单场正文、前进后退、无效场回到首场、窄屏、新增版本自动展示，以及评论新增/编辑/关闭/重开、集场计数即时更新、跨场计数与完整引用及两端定位、草稿隔离和恢复、长块精确定位、刷新持久化、润色上下文及返回原故事/结构。`tests/test_screenplay_summaries.py` 另验证摘要文件缺失、精确修订匹配、热读取和格式错误处理。测试会写入临时评论，不使用正式库或 AI 密钥；重新运行前重启夹具以恢复干净资料。

`tests/test_screenplay.py` 验证整版原子保存、同 ID 不覆盖、Unicode 跨块锚点、评论事件与导出恢复、改编依据固定于原修订。AI 异步结果按当前分集与草稿匹配；切换后迟到的建议不会写入新草稿。真实鼠标圈选和桌面/窄屏检查另在实例验收记录中留证，不把程序化 Range 检查算作真实手势。

## 文本圈选回归

在仓库根目录运行 `PYTHONPATH=. python3 tests/selection_server.py`，浏览器打开 `http://127.0.0.1:8776/selection-tests`。服务创建临时故事实例，使用真实页面、DOM Range 和选区事件检查正文外松手、无变化刷新保留选区、反向跨段、已有高亮、Unicode 字符、容器边界、旧按钮清理、长选区定位及结构稿，并检查正文与结构稿评论准确滚到长块末尾的引用。测试不提交评论，也不使用正式数据或 AI 密钥；页面逐项显示结果，退出服务后临时实例自动清理。

自动用例验证事件处理和引用结果，真实鼠标手势另行核验：在隔离实例的正文中按下，拖到正文右侧空白处再松手，确认按钮出现且能打开包含正确引用的编辑器；同时检查双击与反向拖选。正式实例更新后重新加载页面，复核用户实际入口。

## 故事结构阅读页精简

已选方向后，顶部只保留结构标题、版本切换和必要来源信息；移除方向回看／重选区和重复的“审阅意见”按钮。底部保留意见回应与整体意见，移除供剧本创作的确认入口。底层数据与 API 保持兼容。验证包括现有圈选回归、浮动入口开关、输入框外 Esc 收起后草稿恢复，输入框内 Esc 取消后草稿清除，以及故事采编页回归；真实实例的运行证据归对应故事的验收记录。

结构版本区持续可见，章节目录和正文分别滚动；点击目录只滚动正文，不把外层页面推走。图片延迟载入后仍应对齐所点章节；用户自行滚动、点击、按键或改变评论上下文时停止自动修正。结构和剧本按准确版本保存阅读位置，剧本继续保留版本／集／场组织；重复点击当前版本、集或场不重建正在编辑的草稿。`structure_scroll.test.cjs`、`structure_navigation.test.cjs`、`reading_context.test.cjs` 与 `script_storage.test.cjs` 检查这些状态规则，实际滚动容器和图片载入时序仍需浏览器核对。

制作弹窗的文字选区和浮动评论入口只定位当前最上层完整卡片。背景逐镜正文可能具有相同的块容器 ID；不能用背景节点解释前景选区。修改共用选择处理时仍须真实回归故事采编、结构与剧本文字圈选。

## 高清图显示与区域圈选

在隔离实例使用宽于阅读栏的高清图片和 SVG：桌面及窄屏均应显示完整图幅，图片与叠层的显示宽高一致。逐张点击照片与 SVG，检查当前页面内的大图、右上角关闭和 Esc 关闭，关闭后回到原阅读位置；检查键盘打开、焦点恢复、历史版本与窄屏。大图关闭不应连带关闭原评论面板。拖动圈选后检查区域草稿，不得误触放大；在输入框外按 Esc 收起，再用浮动入口恢复；另在输入框内按 Esc 取消草稿；不向正式实例写测试评论。检查结束恢复临时窗口尺寸，并在真实入口核对图片已加载、静态文件已更新。

正文和完整大卡弹窗都要分别从图片空白处、已有评论区域上开始真实拖选。共用处理器在事件捕获阶段取得原图容器；即使媒体聚焦重绘已移除被点击的旧多边形，也从事件原始路径识别图幅，不因弹窗阻止事件冒泡而漏掉手势。开始前先确定准确素材修订，结束时再核对工作区、目标、阅读容器身份及图片仍在该容器中；弹窗关闭、换版、切页或图片脱离后，迟到松手不得创建别处的草稿。区域坐标按实际图幅归一化，不能用整个预览框计算。`production_image_region.test.cjs` 与 `source_region.test.cjs` 覆盖该契约，真实拖动、提交后的标记和回定位仍单独验收。

## 制作思路与阅读状态

制作思路页改造的隔离回归增加三项：离开再返回故事页保留正文滚动位置、保留未保存的评论草稿，以及两个方法 Tab 随浏览器前进／后退恢复。`tests/selection_server.py --port PORT` 可指定独立端口，避免并行任务共用验收服务。故事与结构的润色任务按准确目标表达；公共项目阶段只在当前意见需要时作背景，不替换稿件自己的事实。

## 故事创作导航与评论总数

故事采编、故事结构、剧本创作均选中一级“故事创作”，各自 Tab 标识当前子页；直接链接、刷新及前进／后退沿用相同导航状态。采编右上搜索框、资料总数及正文“审阅意见”按钮已移除，完整资料列表通过浮动“查看评论”、正文高亮和圈选入口审阅。

采编条目计数绑定 `/api/sources?with_revision=1` 返回的 `target_revision_id`（当前展示内容的对象修订，不是内容文件的摘要）；分类显示“资料 N 项”和所属条目的“评论 N”合计。只有页面显式请求 `with_revision=1` 才返回该字段；默认 `/api/sources` 保持原始资料文档格式，兼容依赖完整文档比较的后台工具。该字段只是 HTTP 响应元数据，不写回资料或公开导出。结构各稿按钮按对象与精确修订计数，包含文字、整篇、整图和区域。计数基于现存评论 UUID 去重，包含已关闭，不计删除记录或编辑／状态历史事件；新增增加总数，编辑、关闭和重开不改变总数。评论重新取得后同步更新，展开状态和菜单滚动位置保留。每页用说明或计数提示标明“包含已关闭评论”。章节只作导航，不要求章节计数。共用面板原有未关闭／历史待决语义保持。

精修资料的章节目录以 `source` 和 `source_chapter` 保存明确选择，后者只能指向该准确资料中既有的章节块。点击目录支持刷新和浏览器前进／后退；切换资料清除旧章节，未知资料或非章节参数不会定位到另一份稿件的同名块。同资料切章只滚动正文，保留正在编辑的评论；恢复时正文须已可见，后来发生的评论定位、编辑或切页优先于排队中的章节滚动。桌面滚动正文容器，窄屏滚动页面并避开顶栏。普通滚动只更新目录高亮，不改 URL 或生成阅读历史；手动切出再返回保留当前阅读位置，刷新与前进／后退则恢复 URL 中明确选择的章节。没有章节参数时使用资料开头，不新增进度或评论数据。

运行一次性夹具：

```bash
PYTHONPATH=.:tests python3 tests/creation_ui_server.py --port 8803 --evidence /tmp/creation-ui.json
```

打开 `/creation-ui-tests`，点击“运行界面统一检查”；每轮需重启夹具恢复初始评论。检查三页导航、入口移除、零／多／关闭评论、分类合计、历史 SOURCE 修订隔离、两稿与四种结构锚点、新增／编辑／关闭／重开、独立接口新增后重新获取、UUID 去重、刷新持久化、章节展开收起，以及桌面／窄屏的标题与计数边界。历史 SOURCE 修订仅在临时数据库构造，生产导入仍保持不可变语义。夹具另删除一条测试记录及其审计行，确认零评论资料不被曾存在的评论计入；实际计数始终读取现存记录。

联合验收沿用上述快捷键、剧本集场和文本圈选夹具；真实鼠标拖到正文外松手、真实 Enter／⌘+Enter／Esc 另在隔离页面操作。正式入口只读核对，不写测试评论。实际实例运行版本和页面证据归故事仓库。

## 制作原件与时间段评论

制作说明复用文字／整体意见；图像区域复用 normalized points，`visual_id` 为所选文件组成 ID。音视频新增 `time` 锚点，记录 `component_id`、`asset_file`、开始与结束秒数；外层仍绑定对象与不可变修订。服务端核对 SHA、文件组成和时长，拒绝越界、非有限数值或版本错配。点击“定位原圈选”切回对应组成；时间评论将播放器定位到起点，图像评论恢复精确区域。新增候选不迁移旧评论。

自动契约验证运行 `python3 -m unittest discover -s tests -p 'test_production*.py' -v`。实际浏览器应操作：播放原件、选时间段并用 ⌘+Enter 保存、回定位、切换历史版本检查评论隔离、拖动图像区域并并排比较；同时回归故事采编、历史结构图文、剧本文字圈选及切页草稿保留。只在隔离实例创建测试意见，不把播放器计时推进当作实际听辨，也不用 HTTP 上传成功替代文件选择器操作。

实例的实际浏览器结果、环境限制和未验项保存在对应故事证据中；这里的接口或事件测试不替代现场结果。素材上传由后台入口完成，不据旧文件选择器的历史验收推断当前页面能力。

## 制作设定内的整实体审阅

实体卡的评论面板汇总当前实体、全部完整状态及关联素材的意见，并保留历史版本意见。切换状态不缩小评论集合；定位意见时加载它的原文字或原文件，历史内容明确标注。声音时间评论在媒体元数据加载后保持准确起点，正文分行／折叠以 `data-anchor-offset` 保存 Unicode 偏移；非连续片段间不生成跨段误引用。

实体内容生成或修订后直接可审阅，没有送审步骤。采纳认可基础信息、关系、所有完整状态与生成方案，取消保留原记录及执行输入；新评论、新候选不改变采纳。隔离验证应覆盖采纳／取消／再次采纳、变更后重新认可、准确历史、并发和恢复。契约在 [generation-preparation.md](generation-preparation.md)，自动验证由 `test_generation.py`、`test_entity_review.py` 与前端测试共同覆盖。

可评论的正文、图像和播放器统一使用轻边线与评论图标；待确认常驻展开，版本选择靠近各内容。图像占位和缺音频条绑定具体需求，真实音频不得显示人物占位图。真实浏览器需核对波形解码、拖选和手柄、数字精调、试听选段、提交后的即时评论标记、回定位及关联范围的原件绝对时间。解码失败保留时间轴；无波形不等于无文件。

整实体审阅的浏览器回归还需覆盖 Unicode、故事／结构／制作思路、准确历史定位与草稿隔离。图片旧区域继续定位准确原件；窄屏检查实际宽度、滚动宽度及页面末尾。播放器推进只是交互验证，不证明声音已实际听辨。技术评论和决策不得导回正式库，实际部署及恢复证据由故事实例保存。

实体关系说明、素材原始生成模型／参数／提示词使用相同文字评论表面。验证旧内容采纳可取消，关系变更需重新认可，CALL 的历史输入不会被新方案替换；在素材管理点击调用评论后刷新仍保留素材卡。原文件、元数据组成、历史候选、状态方案分别切换，见 [素材卡与关系契约](materials-and-relationships.md)。

## 素材块评论与版本

参考用途意见应归“参考用途”并注明具体两端，旧修订保留历史标识。实操至少包括旧备选A新增、精确定位、重开和编辑，再切换备选B检查意见与草稿隔离；原件区域意见另行定位到准确图像。无真实旧关系意见或已生成下游时，以 `test_reference_purpose.py` 的最小隔离夹具核对旧文锚点和同方案原件归属，明确区别于真实业务实践。实体媒体仅有 `review_state` 的历史关联也必须按其准确状态回到原图。

右上图标可点击或按 Enter／空格打开既有面板，列出该块及所选素材轮次的全部现存评论，含已关闭评论；零评论显示空列表。必须覆盖文字跨块、整图／区域、时间交集、去重与其他块／轮次排除。沿用同一底层方案修订的旧两轮也按评论创建时的素材上下文隔离；定位始终使用准确原锚点。新增、编辑、关闭／重开与本机草稿仍走共用接口。

新建素材评论的正文及待确认请求按素材 ID 和方案版本隔离；已有评论编辑按本页、准确目标修订、评论 ID 和原圈选分别保存。旧无轮次草稿无法推断归属，保留原文供查看／复制，仅在用户明确选择恢复到当前轮次且本轮没有草稿时迁移。切换到另一素材卡时同步撤下已失去锚点的编辑器，原准确范围草稿仍可恢复。旧修订反馈在断响应前已推进历史轮次时，原样重试仍确认原提交；新评论不再推动素材版本。

新增夹具 `tests/material_ui_server.py --port FREE_PORT` 提供完整图幅、同版多候选、混合输入及三层预览；验证几何和交互，不生成媒体。迁移、并发及恢复规则见 [方案版本与候选](material-versions.md)。

## 并行编辑与冲突后的继续处理

同一评论的各页修改分别持久保存正文、准确目标、原圈选及开始编辑的评论版本。刷新保留本页归属；新开或重开的页面从原目标面板中的“未保存的评论修改”查找。恢复另一页的文字在本页建立副本，原稿仍可找；放弃此页修改只清本页编辑。恢复列表中的“放弃这份本机草稿”只移除用户明确选择且仍未变化的那份记录，不删除已保存评论或其他草稿。

编辑框标明修改尚未保存以及开始依据。可以随时“查看最新已保存内容”，核对后点击“已核对，按此版本继续修改”，人工整理文字再保存；核对动作不自动合并正文。列表刷新不能更新开始版本。保存冲突时保留原稿并给出中文继续入口，再次变化仍由服务端拒绝。旧共享草稿没有可证明的开始版本，必须先明确核对。网络结果未知时重试保持原开始版本；保存成功后清理失败仍保留成功回执，重试只清理本机内容。

本机存储不可用时当前输入、开始依据和选区仍在本页面，发送失败不清稿；刷新、关闭或浏览器崩溃后的持久恢复只在存储正常时保证。查看润色参考、等待本机可控建议、人工采用及返回编辑复用原机制，迟到响应须同时匹配原编辑过程、准确目标和正文，不能复活已放弃的编辑。

自动检查使用 `comment_edit_concurrency.test.cjs`、`comment_cleanup.test.cjs`、`story_workspace_drafts.test.cjs`、`comment_location.test.cjs` 和 `polish_draft.test.cjs`。真实浏览器另重走 B 先填→A 保存→B 跨页返回→查看新版→人工合并保存，以及冲突→刷新／重开→找到原稿→明确放弃，覆盖另一页取消、另一评论、旧稿换版、制作原件与润色参考返回。模拟响应、接口准备和原生窗口焦点分别标注；自然 focus 若未操作，不写成已验证。
