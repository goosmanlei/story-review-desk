# 评论能力核对清单（旧审阅台 → 本项目 V1）

对照来源：本机历史 `story-review-desk/web/app/story-comments.tsx`、`closed-comment-history.tsx` 和 `tests/entity-comments.ui.mjs`，2026-09-21 只读核对。历史目录与本项目无代码或数据继承关系。

| 旧版可见行为 | 新版 V1 | 验证方式 |
| --- | --- | --- |
| 圈选文本，就近出现“添加评论” | 双击、拖选、反向及跨段选区共用处理；在正文外松手仍触发，按钮跟随可见选区末端，清除选区或切换工作区时收起 | 隔离浏览器回归及真实鼠标拖选；服务端原文 quote 校验 |
| 草稿取消或收起后不丢失 | 未提交新评论按资料与精确锚点保存在本机浏览器 | 浏览器重新圈选同一文字核对 |
| 评论绑定精确文本与上下文 | 稳定对象 ID、精确修订 ID、正文块 ID、起止字符、quote；资料仍兼容 source_id；服务端拒绝错配 | 单测含跨块、Unicode 罕字与对象换版后旧评论不漂移 |
| 提交、编辑、关闭、重新打开 | 四种操作及版本并发保护 | 浏览器与单测 |
| 正文高亮、评论面板定位原圈选 | 高亮、点标记开评论、从评论滚回精确圈选；长章或长结构块不再定位到整块中点 | 隔离浏览器检查长块末尾引用进入可视区 |
| 评论浮窗快捷关闭 | Esc 或点击浮窗外收起；浮窗内操作不触发关闭，收起后可重新打开未保存的编辑状态 | 2026-09-22 本机浏览器验证 |
| 未关闭评论计数、已关闭历史分页 | 按资料计数，历史每次显示 20 条 | 浏览器/代码 |
| 刷新或重启仍保留，关闭记录保留事件 | SQLite 本机持久化；导出包括全部评论与事件 | 重启/恢复验收 |
| 过期评论不静默移位 | 正文 ID 不可原地修改；导入/恢复时重验 quote | 冲突单测 |
| AI 润色建议先预览再应用草稿 | 先展示背景、创作阶段、邻近原文及各版本资料等参考信息；确认后调用 OpenAI Responses API；建议仅供手动采用，永不自动提交 | 浏览器、上下文与请求测试；未配置密钥时明确报错 |

结论：通用评论生命周期和对象修订级锚点按新结构重建；当前浏览器资料页只是首个对象适配器。旧版评论还覆盖分集设计和实体，这些创作工作区本次仍未开放；它们可复用同一评论 API、持久化和锚点校验规则。

## 文本圈选回归

在仓库根目录运行 `PYTHONPATH=. python3 tests/selection_server.py`，浏览器打开 `http://127.0.0.1:8776/selection-tests`。服务创建临时故事实例，使用真实页面、DOM Range 和选区事件检查正文外松手、无变化刷新保留选区、反向跨段、已有高亮、Unicode 字符、容器边界、旧按钮清理、长选区定位及结构稿，并检查正文与结构稿评论准确滚到长块末尾的引用；共 14 项，测试不提交评论，也不使用正式数据或 AI 密钥。页面逐项显示结果，退出服务后临时实例自动清理。

自动用例验证事件处理和引用结果，真实鼠标手势另行核验：在隔离实例的正文中按下，拖到正文右侧空白处再松手，确认按钮出现且能打开包含正确引用的编辑器；同时检查双击与反向拖选。正式实例更新后重新加载页面，复核用户实际入口。

## 故事结构阅读页精简

已选方向后，顶部只保留结构标题、版本切换和必要来源信息；移除方向回看／重选区和重复的“审阅意见”按钮。底部保留意见回应与整体意见，移除供剧本创作的确认入口。底层数据与 API 保持兼容。验证包括现有圈选回归、浮动入口开关、Esc 关闭后草稿恢复，以及故事采编页回归；真实实例的运行证据归对应故事的验收记录。

## 高清图显示与区域圈选

在隔离实例使用宽于阅读栏的高清图片和 SVG：桌面及窄屏均应显示完整图幅，图片与叠层的显示宽高一致。逐张点击照片与 SVG，检查当前页面内的大图、右上角关闭和 Esc 关闭，关闭后回到原阅读位置；检查键盘打开、焦点恢复、历史版本与窄屏。大图关闭不应连带关闭原评论面板。拖动圈选后检查区域草稿，不得误触放大；按 Esc 收起，再用浮动入口恢复，最后取消草稿；不向正式实例写测试评论。检查结束恢复临时窗口尺寸，并在真实入口核对图片已加载、静态文件已更新。
