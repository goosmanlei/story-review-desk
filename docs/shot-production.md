# 镜头制作

全剧制作包含镜头制作、场景剪辑、分集成片三个模块。镜头制作先选步骤，再选择场和镜头；旧镜头拆解、镜头生成的链接仍解析到对应步骤。导航合并不改变原五阶段十五项检查的固定身份与历史。

| 步骤 | 制作与验收对象 |
| --- | --- |
| 镜头设计与输入锁定 | 结构化镜头设计；人物、场景、道具和声音的版本与 SHA；空间、关键帧策略、声音分支与剪辑余量 |
| 粗分镜／对白并行 | 构图、动作方向及表演草图；逐条台词、说话角色、临时或正式声音版本 |
| Animatic 锁时 | 本场有序镜头、整帧时长、对白位置、动作节拍和人物卡；实际预演视频及正式审阅 |
| 正式首尾帧 | 单首帧、首尾帧或带中间帧的策略；逐帧版本审阅及集合连续性审阅 |
| 镜头视频 | 覆盖锁定时长及前后剪辑余量的调用包；动作、运镜、一致性与时间验收 |
| 单镜锁定 | 在相邻镜头和声音上下文中通过验收的实际视频版本与锁定清单 |

设计采用与输入锁定分别留痕。V3 镜头设计支持叙事目的、主体、景别、机位、摄影机运动、角色动作、表演、场景光线、声音、时长和衔接的结构化填写；V1/V2 已冻结输入与审阅契约保持不变。

制作设置先保存草稿、预览精确影响，再交受控工作器发布。图片、对白和视频调用包明确模型、提示词、负面提示与参数，实际附件从已采用版本读取，不接受任意路径或凭证。调用包就绪不会自动调用模型。执行授权和领取时再次核对本镜输入、锁时、关键帧集合与剪辑余量，旧调用包不能沿用变化后的条件。

素材管理保留基础素材与制作过程素材两个视图，使用同一素材卡、版本及审阅机制。新建的基础素材需求没有素材族时，可在其生产资料中建立制作资料：选择已采用的精确参考版本，保存并预览调用包，再由受控工作器原子登记素材族、预期输出、工作项和来源绑定。登记不会产生图片或声音，不会改变已有素材的历史。需求或参考版本改变后，旧预览失效；提交结果不明时先重读任务，不能重复登记。

已建档素材的需求、实体或状态语义变化后，原返修入口继续阻断。制作人员可明确选择“建立新制作基线”，核对已发布的新旧差异并填写说明，再保存、预览和发布下一候选的制作资料；永久归属、范围、素材族和原审阅标准保持不变。原调用包、实际版本及审阅历史保留，新候选需在新条件下重新审阅。发布任务使用独立任务编号核查，成功后回到当前制作资料；响应丢失时，没有精确保存内容或任务回执就保持待核实，不能再次提交。

Animatic 使用 24fps、1920×1080 的整帧时间线，支持跨镜对白、静态画面、简单推拉和两行人物卡。工作器生成实际视频并登记文件 SHA；审阅通过才建立锁时证明。时间、画面、叠加层和边界分别计算依赖。局部调整保留仍兼容的本镜锁时与下游，不能把某个历史整场锁当作当前整场已经通过。

镜头计划变化后，可按当前计划新建时间线草稿，旧修订保留。中断或结果不明的预演任务提供独立核查入口，由工作器在排他媒体租约下核验实际文件与登记证明；确认没有输出后才允许另建版本，未登记的文件保留原位。核查不会自动重新渲染，也不等于完成视听审阅。

正式图片仍按各自版本审阅，关键帧集合另检查起止状态和连续性。输入锁、关键帧集合与单镜锁均需精确正式审阅证据；实际观察缺失保留 UNKNOWN。确定性清单和预演使用独立任务及实际登记证明，不伪造模型 Run。结果不明先核对原任务，不自动重试或覆盖已有文件。

“视频生成素材就绪”由当前输入锁、空间、已通过粗分镜和对白、有效锁时、策略所需全部关键帧及联合审阅、完整调用包共同派生。它不代表镜头视频已生成，也不代表单镜或整片已锁定。只读站点只展示允许公开且实际导出的媒体闭包，不恢复本地执行资格。
