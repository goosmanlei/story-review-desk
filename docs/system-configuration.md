# 系统配置

配置管理类型、默认规则、审阅标准和界面；不管理具体故事实体或素材版本。它位于系统管理第二个页签，与使用与初始化、数据与运行并列。内部配置 schema 2.0 与稳定字段保持，界面按任务归为五组。

| 页面分组 | 内部职责 |
| --- | --- |
| 项目与交付 | 故事与审阅台名称、画幅、尺寸、帧率、平台及交付规格 |
| 资料与设定 | 来源核对顺序；主体、状态、表现、关系类型；参考与连续性规则 |
| 素材与制作 | 两级素材分类、图标、色调、媒介、制作方式；阶段与独立交付要求 |
| 审阅标准 | 分集六项、素材和制作产物的专属问题、顺序、NA及失败说明 |
| AI与界面 | 页面展示、协作偏好、能力及入口；偏好不授权实际调用 |

UI 分组不改配置对象身份或版本。原五阶段十五项 canonical 检查保留，创作者使用镜头制作、场景剪辑、分集成片三个模块；镜头制作内按六个步骤推进，全剧导出仍为 PROJECT。固定身份、作用域、口型分支、权利、版本和 SHA 门禁不能通过配置取消。

## 稳定身份与默认值

已使用的类型或分类 ID 不能删除、改换媒介或变成另一业务身份；改显示名保留别名，新类型使用新 ID。instanceId、projectId、episodePlanId 不能靠改名复用到另一故事。

主体回答身份，状态描述年龄、服饰、身体、时辰、天气及情节条件，表现描述制作所需形态。配置只定义这些类型，具体记录在故事设定与素材管理维护。来源角色、读取状态、事实、权利和实际观察彼此独立；未确认值保留 UNKNOWN。

参考规则包括用途、继承、排除、干净母版及派生限制。亲缘必须有确认依据，同一身份参考必须属于同一主体；风格相同不授权复制人脸。实际使用仍由精确输入版本及 SHA 证明。

## 草稿、预览、发布

编辑后保存草稿，预览精确影响，再确认发布。草稿保存不改变当前有效规则；预览展示变更组、显式升级对象及阻断原因。来源、对象状态、发布或正式事件改变后旧预览失效，不能借新 CAS 包装旧内容。

已保存但未发布的草稿可从页尾继续。跨组切换保留修改；离开未保存页面提示。页面不显示“版本与维护”或内部版本列表，历史仍在数据库不可变保存。

新对象采用创建时的默认配置。已有对象及其新媒体版本继续继承原冻结标准；名称或品牌更新不表示审阅规则升级。审阅标准内可逐项选择升级对象，已有采用、执行或源同步依赖会阻断直接升级。不得篡改历史事件、候选、输入或权利事实。

配置模板导入导出移至数据与运行。模板排除实例品牌、具体连续性路径、实例前置引用、迁移专属标准、故事内容、媒体和凭证。导入只保存新草稿，不覆盖已有未发布草稿；预览发布之后才生效。

## 审阅标准与历史

标准目录按故事、素材、制作组织。分集六项必答，首集独立建立、末集收束分别核对；人物身份、信息卡、地点、声音、关键帧、字幕、分轨及报告使用各自的问题与实际证据。已冻结标准及哈希不得借新默认改写。

当前分集输入、正式本集放行、正文源同步、场级制作意图和镜头设计分别留痕，不恢复独立场正文表单或把输入当采用。V2 镜头设计使用独立冻结标准，按完整需求设计采用，不表示实际输入或生成就绪；V1 历史保持原标准。

## 初始化与只读

新建实例登记通用配置；既有实例可先 inspect，再对尚未初始化的实例执行一次 initialize。重复初始化不覆盖已发布规则，后续走草稿和预览。系统配置与设定、素材分别确认，没有整图齐备门禁。

只读镜像展示已发布配置与对象绑定，不接受草稿、初始化、发布或执行。运行与备份见[使用与维护](system-management.md)，数据库隔离见[实例隔离](instance-isolation.md)。
