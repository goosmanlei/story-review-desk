# 页头、控件与配置交互

每个已实现的子页共用 `index.html` 中唯一的 `.page-heading`，按“短标识、页面标题、一句用途说明”表达当前页面。`navigation.js` 的 `workspacePageDescriptor()` 根据工作区及子页路由提供内容；切换子页同时更新标题和用途。窄屏自然换行，不把三个信息层级限定为三个物理文本行。资料目录、章节目录与具体作品标题各有自己的作用，不重复增加一套页面介绍。

四个主入口的子页由统一导航描述：制作思路默认故事创作、生产制作，并按实例扩展视频手册、影视知识等方法页；故事创作的故事采编、故事结构、故事剧本；生产制作的视听制作、实体管理、素材管理；系统管理的故事项目、系统与 AI、编号前缀。新子页在上述描述函数登记自己的用途，复用公共页头，不在视图内部再创建页面级标题。

`desk-theme.css` 最后加载，统一浅色纸面、菜单边框、圆角、字体、行高和间距。固定顶栏下至页头首行的间距为桌面 24 像素、700 像素及以下屏幕 18 像素。选中项除绿色底外还使用边线、字重或勾选标识；键盘焦点有独立轮廓，禁用项不可点击，输入错误有文字说明与边框。正文深色字、评论高亮、媒体原件及波形保持各自语义；不以淡化正文来减少界面深色块。

目录仍支持横向滚动到达更多稿次、剧本版本和分集。实体／素材小卡仍按四列基准行分页，窄屏只重排当前页；大卡内版本和候选继续平铺选择。准确历史、评论、采纳、参考选择和弹窗返回位置沿原契约执行，视觉层不改变业务默认值或引用。

“系统与 AI”把站点图标与评论润色分成两块，一次保存整个 SYSTEM 配置。模型及可选推理强度读取服务端 `catalog.model_efforts`；换模型后保留支持的强度，否则选择该模型支持的默认项。API Key 环境变量名只保存名称；必须以字母或下划线开头，仅含字母、数字和下划线，最多 128 字符。AI 参考总字符上限覆盖完整序列化参考（原文、意见、背景、来源元数据与格式），必须是 1000—30000 的整数，前端标签、帮助与校验范围均从目录提供的约束读取，后端再次校验。

两块输入共同保留草稿、配置版本及待核实的保存请求。无效输入先显示具体字段错误；上传、保存失败或冲突不清空另一块输入。图标上传只准备文件，保存后才应用；结果不明时先回读，禁止假报成功或盲目重写。图标格式、受管文件和导出恢复边界见[图标说明](favicon.md)。

前端检查用 `node --test tests/*.test.cjs`，后端用 README 中的 Python 测试命令。实际页面、上传权限、原件显示和正式运行版本仍须在故事实例中验收；自动测试不替代浏览器结果或用户对视觉和素材的接受。
